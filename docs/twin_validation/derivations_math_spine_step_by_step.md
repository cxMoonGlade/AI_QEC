## 0. The machine and the notation

- n data qubits on a line. X-type stabilizer group 𝒮 with generators g_κ (repetition code:
  g_κ = X_κ X_{κ+1}, κ = 0..n−2; k := n−1 generators). Support homomorphism
  γ: 𝒮 → F₂ⁿ, γ(X^e) = e; image V_S = γ(𝒮) ≤ F₂ⁿ (rep code: the even-weight subgroup for
  n = 3; generally generated by the check supports).
- R rounds. Round r: (i) each qubit q acquires a classical Z-phase φ_{q,r}; the collection
  φ ∈ R^{nR} is zero-mean jointly Gaussian with covariance Σ ("legs" = (q,r) pairs, index
  ℓ = r·n + q). (ii) background Z flip w.p. p_Z per qubit. (iii) every stabilizer measured
  projectively; recorded bit m_{κ,r} = true syndrome ⊕ Bernoulli(p_M) flip; ancilla reset.
- Entry ρ₀ = |+⟩⟨+|^{⊗n}. Exit: (E0) trace = syndrome-only access; (E1) transversal X-basis
  readout x ∈ {0,1}ⁿ with per-qubit flip p_F.
- Z-basis matrix units |i⟩⟨j|, i, j ∈ {0,1}ⁿ. z_q(i) := (−1)^{i_q}.

**Step 0.1 (grade).** Define a_q(i,j) := ½(z_q(j) − z_q(i)) ∈ {−1, 0, +1}; a(i,j) ∈ {−1,0,1}ⁿ.
Check: a_q = 0 ⇔ i_q = j_q, so **supp(a(i,j)) = i ⊕ j** as an F₂ vector. Diagonal units have
grade 0.

**Step 0.2 (F1: dephasing is grade-diagonal).** U_φ = exp(−i Σ_q φ_q Z_q / 2) gives
U|i⟩ = e^{−iφ·z(i)/2}|i⟩, hence U|i⟩⟨j|U† = e^{−i φ·(z(i)−z(j))/2}|i⟩⟨j| = e^{iφ·a(i,j)}|i⟩⟨j|.
(The global sign convention is irrelevant: Gaussian φ is symmetric.)

**Step 0.3 (F2: background is grade-diagonal).** ρ ↦ (1−p_Z)ρ + p_Z ZρZ acts on |i⟩⟨j| with
eigenvalue (1−p_Z) + p_Z(−1)^{a_q} per qubit = 1 on a_q = 0 and (1−2p_Z) on a_q = ±1.
Equivalently: a π-phase flip w.p. p_Z (E[e^{iπ b a}] = (1−p_Z) + p_Z(−1)^a) — the two
implementations are identical, which is why the samplers use π-flips.

**Step 0.4 (grade decomposition of one round).** Write M_a = the projector onto grade-a matrix
units. Expanding the joint Gaussian average of a product of per-round phases over the R rounds:
E_φ[∏_r e^{iφ_r·a_r}] = exp(−½ âᵀΣâ), â = (a_1..a_R) ∈ {−1,0,1}^{nR} — the multivariate
Gaussian characteristic function. This is the ONLY place Σ ever enters. Everything downstream
is bookkeeping of which â carry nonzero machine coefficients.

## 1. The probe calculus (T-B Lemma A)

Goal: express every record functional as a finite sum of CF evaluations e^{−½âᵀΣâ} with
Σ-independent coefficients, and show the support of â is DETERMINISTIC given the probe pattern.

**Step 1.1 (Walsh characters are enough).** The record (m, x) is a finite bit string; its
distribution is determined by all parities W(u, χ) = E[(−1)^{Σ_r u_r·m_r + χ·x}], u_r ∈ F₂ᵏ,
χ ∈ F₂ⁿ (Fourier on the Boolean cube — invertible). So prove things for W(u, χ).

**Step 1.2 (assignment noise dresses and de-noises).** For one recorded bit,
Σ_{m}(−1)^{um} Pr[m|s] = (1−p_M)(−1)^{us} + p_M(−1)^{u(s⊕1)} = (1−2p_M)^{u}(−1)^{us}.
Product over probed bits: W = ∏_{r}(1−2p_M)^{|u_r|} · (1−2p_F)^{|χ|} · W^{true}, where W^{true}
uses TRUE syndromes/readout. From here work with true bits.

**Step 1.3 (the character-summed round map C_u).** The syndrome-s projector is
P_s = 2^{−k} Σ_{h∈𝒮} (−1)^{s·idx(h)} h, idx(h) ∈ F₂ᵏ the generator-exponent vector (finite
abelian group character expansion; verify: apply both sides to a stabilizer eigenstate).
Then
  C_u(ρ) := Σ_s (−1)^{u·s} P_s ρ P_s
          = 4^{−k} Σ_{h,h'} [Σ_s (−1)^{s·(u ⊕ idx h ⊕ idx h')}] h ρ h'
          = 2^{−k} Σ_{h∈𝒮} h ρ (h·g_u),          g_u := ∏_κ g_κ^{u_κ},
because the s-sum forces idx(h') = idx(h) ⊕ u, i.e. h' = h·g_u. **Key structure: probing
character u inserts the RELATIVE bra-ket string g_u; the free h-sum is same-on-both-sides.**
Unprobed round (u = 0): C_0(ρ) = 2^{−k} Σ_h hρh.

**Step 1.4 (support propagation under X^a ρ X^b).** X^a|i⟩⟨j|X^b = |i⊕a⟩⟨j⊕b|; new support
= (i⊕a) ⊕ (j⊕b) = supp ⊕ (a⊕b). For C_u terms: a = γ(h), b = γ(h g_u) = γ(h) ⊕ γ(g_u) ⇒
**every term shifts the support by exactly γ(g_u)** (h drops out of the support algebra).
Sign propagation (needed later): for q ∉ supp-change, a'_q = (−1)^{h_q} a_q (both sides
flipped together); for q where the support toggles 0→±1, the new sign is set by the resident
diagonal byte; where ±1→0 the coordinate closes. The h-sum therefore averages SIGNS but never
moves SUPPORTS.

**Step 1.5 (exit rules).** Trace: Tr|i⟩⟨j| = δ_{ij} ⇒ selects final support 0.
Readout character: Σ_x (−1)^{χ·x}|x⟩⟨x| = X^χ (verify on one qubit: |+⟩⟨+| − |−⟩⟨−| = X),
and Tr[X^χ |i⟩⟨j|] = δ_{j, i⊕χ} ⇒ selects final support χ. With p_F: dressed by (1−2p_F)^{|χ|}
(Step 1.2 applied to readout bits).

**Step 1.6 (support-path determinism).** A round is M_{a_r} then C_{u_r}. Grade a_r can be
selected only from what arrives; the arriving support after round r−1 is σ_{r−1} ⊕ γ(g_{u_{r−1}}).
Recurse BACKWARD from the exit condition σ_R ⊕ γ(g_{u_R}) = χ:
  **σ_r(u, χ) = χ ⊕ ⊕_{r' ≥ r} γ(g_{u_{r'}}).**
The entry imposes NO constraint (|+⟩⟨+|^{⊗n} = 2^{−n} Σ_{ij}|i⟩⟨j| contains every grade with
coefficient 2^{−n} > 0). Conclusion:
  W(u, χ) = (dress) · Σ_{â: supp(a_r) = σ_r ∀r} T(â) (1−2p_Z)^{#graded legs} e^{−½âᵀΣâ},
with T(â) ≥ 0 (every factor along the chain — entry 2^{−n}, the 2^{−k} h-sums, diagonal
propagation — is nonnegative; no signed cancellations exist because Step 1.3 removed all
(−1)^{s·u} signs).

**Step 1.7 (Corollary: locality, windows, reach).**
(i) The moment depends on Σ only through entries {(q,r),(q',r')} with q ∈ σ_r, q' ∈ σ_{r'}.
(ii) A detector D_{κ,r} = m_{κ,r} ⊕ m_{κ,r+1} probes u_r = u_{r+1} = e_κ; the backward XOR
telescopes: σ_j = γ(g_κ) for j = r+1 ONLY, 0 elsewhere — **a single-leg window on the check's
support**. XOR-ing detector sets XORs their windows. Bulk detector moments are therefore
exactly LOCAL, and the functional FORM is translation-covariant (the same function of the
window block, applied at each position). ⚠ EQUALITY of expectations across r is NOT part of
the theorem — it additionally requires the window blocks to be equal, i.e. a STATIONARY Σ
(model/data assumption: the teacher truths are stationary by construction; on hardware it is
the prereg-S2 declared simplification, gated by the detection-stats layer-flatness check).
(iii) A bare m-character (u at one round, no partner) has σ_j = γ(g_u) for ALL j ≤ r — an
entry-anchored window: the parity-walk nonstationarity, exact.
(iv) Reach: probing the product of j consecutive rep-code checks gives
γ(g_κ⋯g_{κ+j−1}) = {κ, κ+j} (supports telescope), so an order-j same-round detector product
reads the qubit pair at distance j. This is the order↔reach ladder.

Checkpoint: `tb_ident_gauge_verify.py` V1 (law below), V2 (outside-window perturbation moves
the moment by exactly 0; inside moves it) — log v4: 0.00e+00 / 3.31e-03.

## 2. The re-signing gauge theorem (T-B Theorem 1, amended form)

**Claim.** Let ε ∈ {±1}^{n×R} be leg-wise signs whose consecutive-round increments are
stabilizer supports: ε_{·,r+1} ⊙ ε_{·,r} ∈ V̂_S := {(−1)^v : v ∈ V_S}, the first ROUND's
(global) pattern arbitrary.
Then Σ and E_ε Σ E_ε produce identical records (all W(u,χ), all orders, both exits, any
p_Z/p_M/p_F).

**Step 2.1 (decompose ε).** ε = (global pattern w₀ on all rounds) ⊙ (suffix increments
v_b ∈ V_S at boundaries b): ε_{·,r} = w₀ ⊙ ∏_{b<r}(−1)^{v_b}.

**Step 2.2 (global pattern w₀ — any qubit subset).** Conjugate the whole circuit by
X_W = ∏_{q∈W} X_q. Check every element: U_φ ↦ U_{S_Wφ} (X Z X = −Z); P_s: X-type, commutes;
background: X(ZρZ)X = Z(XρX)Z inside the mixture ⇒ channel commutes; assignment noise:
classical; reset: basis-free; entry: X_W|+⟩^{⊗n} = |+⟩^{⊗n}; X-readout projectors:
X_W|x⟩⟨x|X_W = |x⟩⟨x|. Net effect: the record of field φ equals the record of field w₀⊙φ.

**Step 2.3 (suffix increment v ∈ V_S at boundary b — THE step that was terse; write it fully).**
Insert X^v X^v = I immediately after the round-b measurement. Push the RIGHT X^v through the
suffix: it commutes with every X-type machine element, re-signs every suffix dephasing leg on
supp v (as in 2.2), and dies at the exit (trace is conjugation-invariant; X-readout projectors
invariant). The LEFT X^v must be absorbed AT the boundary: immediately after the round-b
measurement the quantum state lies inside the TRUE syndrome sector (the recorded bit may
differ by the p_M flip — irrelevant: the flip is classical and the absorption acts on the
state) — the joint eigenspace of the stabilizer group — on which X^v = X^{γ(h_v)} for
h_v ∈ 𝒮 acts as the SCALAR (−1)^{s_b·idx(h_v)} (s_b = the TRUE syndrome; the value is
immaterial since a modulus-1 scalar conjugates away).
Conjugation by a scalar is the identity. **This is exactly why increments must sit at round
boundaries (only there is the state sector-pure) and lie in V_S (only stabilizer strings act as
scalars).** Net: record(φ) = record(ε ⊙ φ) pathwise.

**Step 2.4 (Gaussian).** Re-signing a Gaussian field is the congruence Σ ↦ E_ε Σ E_ε (still
PSD). ∎

Consequences to verify yourself: (a) flipping the SIGN of any cross-WINDOW covariance block of
a same-check detector pair is a suffix-flip instance ⇒ every temporal relative sign is
gauge-erased; (b) a single cross-entry sign flip is NOT in the group (group elements flip
≥4-entry patterns) ⇒ must move some moment (alive control).
Checkpoint: V3/V3b (gauge ≤ 2.2e-16 incl. composed patterns; non-admissible increments move
8.4e-3 / 7.0e-5).

> **TRAP 1 (falsified by run 1 of the T-B verification).** First registered claim: "for the

## 3. The order-1 and order-2 laws (T-B Theorems 2, Prop 3)

**Step 3.1 (state at window-open is exactly I/2ⁿ).** Before the probed window all supports are
0 (Step 1.6), i.e. only the diagonal component propagates. Entry diagonal component:
2^{−n} Σ_i |i⟩⟨i| = I/2ⁿ. Diagonal propagation through C_0 = 2^{−k}Σ_h hρh: X-strings permute
the computational basis ⇒ unital on diagonals ⇒ I/2ⁿ is a fixed point. So the window opens
from I/2ⁿ regardless of r.

**Step 3.2 (opening probe).** C_{e_κ}(I/2ⁿ) = 2^{−k}Σ_h h (I/2ⁿ) (h g_κ) = 2^{−n} X^{γ(g_κ)}
(h·h = I inside; 2^{−k}·|𝒮| = 1). Note X^γ = Σ_i |i⟩⟨i⊕γ⟩: EVERY sign pattern of grade
support γ appears with equal coefficient 2^{−n}.

**Step 3.3 (window leg + closing).** The next dephasing selects grade a on supp γ (weight
e^{iφ·a} → CF later); the closing probe C_{e_κ} maps grade-a to diagonals (h-sum again
uniform), the remaining rounds are diagonal, the exit trace is uniform. All sign patterns a
carry the SAME machine coefficient. Collect dressings: 2 probes ⇒ (1−2p_M)²; |γ| graded legs
⇒ (1−2p_Z)^{|γ|}. Normalize with the Σ=0, noiseless value 1:

  **E[(−1)^{D_{κ,r}}] = (1−2p_M)² (1−2p_Z)^{w} · 2^{−w} Σ_{a∈{±1}^{w}} e^{−½ aᵀ B a},**

B = the window-leg block on supp γ (w = |γ|; rep code w = 2 gives
(1−2p_M)²(1−2p_Z)² e^{−(V_q+V_{q'})/2} cosh C_{qq'}).

**Step 3.4 (sanity by an independent 2-qubit computation).** |++⟩ →(phases)→ each qubit
cos(φ/2)|+⟩ − i sin(φ/2)|−⟩; odd-parity probability = cos²(φ_q/2)sin²(φ_{q'}/2) +
sin²cos² (orthogonal targets ⇒ no interference) = ½ − ½cos φ_q cos φ_{q'};
E[cos a cos b] = ½[e^{−½(V_a+V_b+2C)} + e^{−½(V_a+V_b−2C)}] = e^{−(V_a+V_b)/2}cosh C. Matches.

**Step 3.5 (consequences).** cosh ≥ 1 ⇒ within-window covariance of EITHER sign RAISES
E[(−1)^D], i.e. LOWERS the detection rate at pinned marginals — the quieter-scissors
direction, analytically; and the leading response is O(C²) — the mechanism of the record-layer
s²-dilution arithmetic.

**Step 3.6 (order-2, single-check machine, lag-1).** Windows = legs r+1, r+2 (contiguous;
probes at r and r+2, the middle cancels ⇒ dressing (1−2p_M)² only). Interior C_0 locks
a₂ = ±a₁ uniformly (Trap 1) ⇒
  W = (1−2p_M)²(1−2p_Z)⁴ · ¼ Σ_{a∈{±1}²} e^{−½aᵀ(B₁+B₂)a} cosh(aᵀ Σ_× a),
and expanding the two a-classes: cosh(A+B̃) + cosh(A−B̃) = 2 cosh A cosh B̃ with
A = Σ^×_{qq} + Σ^×_{q'q'}, B̃ = Σ^×_{qq'} + Σ^×_{q'q}. Lag ≥ 2: two disjoint windows, the
diagonal segment between them factorizes the coefficients ⇒ doubly-uniform hypercube average
(same evenness). Checkpoint: V4 order-2 law 1.11e-16.

**Step 3.7 (interior erasure by counting).** For a chain interior, restrict the h-sum to the
window support γ: the achievable relative flip patterns are {h|_γ : h ∈ 𝒮}. Count them:
neighbors contribute 10 and 01 restrictions, the check itself 11 ⇒ ALL FOUR patterns, each
from exactly ONE coset ⇒ the relative-sign average is UNIFORM ⇒ full erasure (certified:
PAIR2 lag-1 flip invariance 1.1e-16). For the single-check machine only {00, 11} ⇒ the
aligned-flip cosh of Step 3.6.

## 4. T-#2: the silent-floor functional

**Step 4.1 (the event = one record point).** Silent-and-flip = {all m = 0} ∧ {terminal seam
quiet} ∧ {logical flipped}. Terminal seam quiet ⇔ recomputed syndrome of the recorded x is 0
⇔ x ∈ {all-zeros, all-ones}. Within that set, the logical-flip label is REPRESENTATIVE-
INDEPENDENT: x = all-ones flips every logical representative (X̄ ≃ X_q mod 𝒮 for each q), so
flip ⇔ x = all-ones — for EVERY n. (⚠ the "obs = full parity of x" reading is the odd-n /
tier-1 d=3 convention only; for even n the full product ∏_q X_q is a STABILIZER, its parity on
all-ones is 0 — use the representative-independent flip label, which is exactly what the
scripts compute: Pr[m̄ = 0, x = 1⃗].) So the event is the single record outcome
(m̄ = 0, x = 1⃗), matching the tier-1 fold convention (det0 = m₁; body XOR; seam) — prove the
⇔'s yourself; they are bijective XOR re-encodings.

**Step 4.2 (exact functional by Walsh inversion).**
  F(Σ) = Pr[m̄=0, x=1⃗] = 2^{−kR−n} Σ_{u,χ} (−1)^{χ·1⃗} W(u, χ),
and each W is a Lemma-A CF sum ⇒ **F is a finite Fourier sum of Gaussian characteristic
functions with machine coefficients, for arbitrary Σ** — the interpolating functional.

**Step 4.3 (leading order — derive the amplitude, then the moment).** At zero dressing and
small Σ: a single round's collective flip has amplitude ∏_q(−i sin(θ_{q,r}/2)) (each qubit's
Z-rotation must flip; any PARTIAL flip changes some check's parity ⇒ detected ⇒ excluded from
the silent event; verify: a single-qubit flip anticommutes with its two neighboring checks).
Crucially, no detector distinguishes WHICH round a collective flip occurred in ⇒ the R
amplitudes add COHERENTLY before squaring:
  F = 4^{−n} E[(Σ_{r} ∏_q θ_{q,r})²] · (1 + O(Σ)) = 4^{−n} Σ_{r,r'} E[m_r m_{r'}] · (1 + O(Σ)),
m_r := ∏_q θ_{q,r}  (both equalities leading-order; the exact object stays Step 4.2's sum).

**Step 4.4 (the n = 3 curve).** Isserlis for E[θ₁²θ₂²θ₃²] with equal marginals σ², uniform

itself's partner (σ⁶ term ×1... do it properly): classes are (i) all three pairs within the
same variable: (θ₁θ₁)(θ₂θ₂)(θ₃θ₃) → σ⁶, 1 way; (ii) one variable self-paired, other four legs
cross-paired: 3 variables × 2 cross-pairings = 6 ways → σ²·(ρσ²)² = ρ²σ⁶; (iii) all cross:
8 ways → (ρσ²)³ = ρ³σ⁶. Total E = σ⁶(1 + 6ρ² + 8ρ³); ρ = 1 gives 15 = 5!! (the Clader endpoint,
cited never claimed). So F(ρ)/F(0) → 1 + 6ρ² + 8ρ³.

**Step 4.5 (the n = 2 interference law).** E[(Σ_r m_r)²] = Σ_r E[m_r²] + Σ_{r≠r'}E[m_r]E[m_{r'}]

(R=2 → 4 at ρ=1: the falsifying number). Rate-based simulators produce only the diagonal —
the falsifiable separation.

**Step 4.6 (metric theorem ∂F/∂f|₀ = 0, two proofs — do both).**

patterns: each cross-qubit contribution is odd under some flip ⇒ derivative = 0. Exactly.

â_{qℓ}â_{q'ℓ'} which is odd under the same symmetry of (c, w₀) at f = 0; group â with −â.
Corollary: the honest metric is ∂²F/∂f² (coefficient 6 per round-block, n=3 uniform) plus the

## 5. T-L2 theorems (amended forms)

**Step 5.1 (Thm L2-1, with its hypotheses).** Hypotheses: [H, Π_z] = 0 (pointer-diagonal
Hamiltonian) and classification-only measurement noise. Then for a GKSL unit with only σ±
dissipators: on diagonal inputs, ρ̇_ee = −γ↓ρ_ee + γ↑ρ_gg (coherences never source populations
— check the σ_x-drive counterexample: ṗ_e ⊃ −Ω Im ρ_eg ≠ 0, which is WHY the hypothesis is
needed). Post-measurement states are pointer states ⇒ the TRUE pointer-state process is a 2-state
Markov chain with kernel T(τ_m) = exp(τ_m Q), Q (e,g-ordered, column-stochastic generator) =
[[−γ↓, γ↑],[γ↓, −γ↑]], π = (γ↑, γ↓)/Γ, Γ = γ↓+γ↑ — identical to the classical telegraph.
With p_M > 0 the OBSERVED record is that chain seen through i.i.d. binary-symmetric emission —
an HMM, not itself Markov (the Step-5.2 observed-flip statistics are computed on exactly this
HMM).
Kernel entries: a := P(e→g) = (γ↓/Γ)u, b := P(g→e) = (γ↑/Γ)u, u = 1 − e^{−Γτ_m}.
Embeddability: a + b = u < 1 always; conversely any 2×2 stochastic kernel with a+b<1 is
exp(τQ) (Γτ = −ln(1−a−b)) — necessary and sufficient (det T = 1−a−b > 0).
AMENDMENT (A-L2-1 item 1): the M3 null must be matched to the exact window KERNEL (a,b), not
to TCL2 rates — the mode-reset JC record is exactly Markov at any (g,κ), but its kernel equals
exp(τ_m Q_TCL2) only to O(g²); the O(g⁴) gap is the signal order.

**Step 5.2 (Prop L2-3 exact statistics — derive all four).** Stationary chain sampled at τ_m.
(i) TRUE-flip conditioning: after an observed TRUE e→g flip the state is g; conditional next-
window flip = b; unconditional flip = π_e a + π_g b = 2ab/(a+b); excess = b − 2ab/(a+b) =
b(b−a)/(a+b) < 0 ⇔ b < a ⇔ γ↑ < γ↓ (thermal). Ratio at N̄→0: cond/unc → (a+b)/2a = Γ/2γ↓.
(ii) OBSERVED-flip conditioning with p_M (the amended statistic): build the 2×2×2 joint of
(true state r, recorded flip) — the conditioning event mixes true flips with noise flips.
Sticky regime a, b ≪ p_M: the record is dominated by noise flips on a frozen state; work the
limit: excess → (1−2p_M)(π_e − p_M), POSITIVE iff π_e > p_M (the amended condition).
(iii) N̄ = 0 (γ↑ = 0, absorbing g): p_M = 0 ⇒ conditioning event has probability 0 (0/0);
