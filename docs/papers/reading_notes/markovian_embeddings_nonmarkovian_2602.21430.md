## 2. 核心统一框架

本文回答了以下问题：**为什么存在如此多"数值精确"的非马尔可夫方法（HEOM、Lindblad-伪模式、热场-MPS），它们之间有何关系？**

核心主张：所有方法都是**马尔可夫嵌入**——将系统在线性耦合到高斯浴的精确 Feynman-Vernon 影响泛函，通过**自能 (self-energy) 分解** `Σ = U† G V` 因子化，再用高斯路径积分恒等式引入辅助场 Ψ，从而转化为**时间局域**的运动方程。不同的嵌入对应 `G(t)` 的不同代数形式，并通过 Bogoliubov 变换（方程 14）相互关联。

### 2.1 自能 Σ = U† G V 分解 — 所有嵌入的共同起源

**出发点 (§II, Eq. 8-11):**

影响相位 `Φ(t)` 是经典/量子超算符的双线性形式:

```
Φ(t) = ∫₀ᵗ dτ du [S_q(τ) S_c(τ)] Σ(τ-u) [S_q(u); S_c(u)]
```

其中 `S_{c/q} ρ̂ = (1/√2)(Ŝρ̂ ± ρ̂Ŝ)`（方程 9）。

**自能 Σ(t) 不是唯一的**——因为 `C(t)†=C(t)` 且积分域对称，且 Φ 不依赖于 Σ 的反对称部分。本文给出两种等效表示:
- **方程 10** (时序 + 反时序): `Σ(t) = [[-i, -iθ(t)],[iθ(-t), 0]] C(t)`
- **方程 11** (仅时序, 实/虚部分离): `Σ'(t) = -2iθ(t)[Re C(t)·[[1,0],[0,0]] + Im C(t)·[[0,i],[0,0]]]`

**核心 ansatz (§II A, 方程 12):**

```
Σ(t) = U† G(t) V
```

其中:
- `G(t)` (秩 K) 满足非齐次局域微分方程 **`K(i∂τ) G(τ) = δ(τ) 1`**（方程 13）
- `K` 是常数矩阵 + 非零元素为 ±i∂t 的矩阵之和
- `U†` 和 `V` 是时不变矩阵

**精确性声明:** 对于多指数相关函数 `C(t)` 精确；对于一般 `C(t)`，当秩 K 充分提高时可达到任意精度。

### 2.2 三种嵌入框架

本文给出了三种 `G(t)` 的选择，对应三种不同的马尔可夫嵌入:

| 嵌入框架 | G(t) 结构 | 方程 | 辅助初态 / 读出 | 退化为 |
|---|---|---|---|---|
| **(A) Keldysh / 三角嵌入** | `G=[[G_K, G_R], [G_A, 0]]` | Eq. 27 | 热态 `n_ref`, 偏迹 (partial trace) | Lindblad-伪模式 (n_ref=n_β); HEOM (n_ref=0) |
| **(B) 纯态 / 块对角嵌入** | `G=[[G(t),0], [0,-G†(-t)]]` | Eq. 38 | 真空, 真空投影 | HEOM (各种变体) |
| **(C) Hilbert-空间 / 单推迟格林函数** | `G(t)=-iθ(t)e^{-iEt}` | Eq. 47 | 真空 `|0⟩` | HEOM (Ref. [42] Eq. 20); Nambu-Keldysh 稳定 HEOM |

### 2.3 Bogoliubov 变换 — 方程 14 作为规范自由度

**方程 14（逐字记录）:**

```
U'† = U† L⁻¹,   G' = L G R⁻¹,   V' = R V
```

任何可逆线性变换对 (L, R) 作用在 (U†, G, V) 上产生等效三元组，保持方程 12 的乘积 `Σ = U† G V` 不变。

**物理意义:** 这种规范自由度对应辅助模式空间的 **Bogoliubov 变换**。具体地:
- 方程 43: `B = e^{-â+ â†_-} e^{iπ â†_- â_-}` — 将块对角嵌入（方程 42）映射到 Keldysh 嵌入（方程 37）的相似变换
- 方程 56: 将 Hilbert-空间嵌入（方程 55）映射到 Nambu-Keldysh 稳定框架（方程 57）
- 热场变换 (thermofield transformation) 是 Bogoliubov 变换的一个特例（§IV 文本）

**关键洞察 (§IV, 第 8-9 页):** Bogoliubov 变换在精确动力学下保持物理不变性（相似变换保谱）。但在**截断**下，截断投影与变换**不对易** → 截断后的有限维 Liouvillian 是表示依赖的 → **不同框架下的截断误差分布不同**。这使得框架选择成为重新分配截断误差、提高数值稳定性的自由旋钮。

### 2.4 Keldysh/三角形嵌入 → 显式 Lindblad EOM

Keldysh Green 函数矩阵（方程 27）:

```
G(t) = [[G_K(t), G_R(t)], [G_A(t), 0]]
```

- `G_R(t) = -iθ(t) e^{-i(ζ-iγ₀)t}` (推迟, 方程 17a)
- `G_A(t) = iθ(-t) e^{i(ζ+iγ₀)t}` (超前, 方程 17b)
- `G_K(t) = (2n_ref+1)(G_R - G_A)` (Keldysh, 方程 28), `n_ref` 为参考占据数

逆核（方程 30）:

```
K(i∂t) = [[0, i∂t-(ζ+iγ₀)], [i∂t-(ζ-iγ₀), 2iγ₀(2n_ref+1)]]
```

**薛定谔绘景下的嵌入 EOM（方程 33，逐字记录）:**

```
ρ̇̂(t) = -iL₀ρ̂(t) + γ₀(n_ref+1)[2âρ̂â† - {â†â, ρ̂}] + γ₀n_ref[2â†ρ̂â - {ââ†, ρ̂}]
```

- 这是**一个带标准 Lindblad 耗散项的阻尼玻色子伪模式**（速率 `γ₀(n_ref+1)` 向下, `γ₀n_ref` 向上）
- `L₀`（方程 34）携带 `Ĥs + ζâ†â` 加上系统-模式耦合
- 约化密度算符 = **对伪模式求偏迹**（方程 32），模式初态为**热态 `n_ref`**

**示例 1**（方程 35）: 在弱阻尼准热极限（方程 20）且 `n_ref=n_β` 下，退化为**传统 Lindblad-伪模式方程**[Refs. 26-28]，哈密顿系统-模式耦合 `(c₀/√(2ζ))Ŝ(â+â†)`。

**示例 2**（方程 36-37）: `n_ref=0` 且 `γ₀=0` → ADOs `ρ̂_{k,l}=(l|ρ̂|k)` 恢复 **HEOM 结构**（与 Ref. [65] 的方程 22 相同）—— n_ref=0 将所有高阶 ADO 初始化为零（HEOM 真空性质）。

## 3. 关键方程（逐字记录）

### 方程 2 — 浴相关函数定义

```
C(t) = ⟨X̂b(t) X̂†b(0)⟩_b
```

其中 `X̂b(t)` 是算符值高斯噪声，`⟨·⟩_b` 表示对浴自由度的系综平均。浴仅由其两点相关函数完全刻画（高斯浴定理）。

### 方程 14 — Bogoliubov 变换（规范自由度）

```
U'† = U† L⁻¹,   G' = L G R⁻¹,   V' = R V
```

这是生成所有嵌入之间映射的李代数结构。

### 方程 18 — 洛伦兹谱密度（最小物理模型）

```
J(ω) = 4c₀²γ₀ω / [(ω² - ω₀²)² + 4γ₀²ω²]
```

**物理起源:** "宽带 Ohmic 浴被中心频率 ω₀ 的单个谐振模式滤波后的有效谱密度"[53]。这是在化学物理和量子光学中广泛使用的**最小物理模型**。三个极限:
- **极限 1 — 经典/高温 (Eq. 19):** 忽略 Matsubara 项后的经典相关函数
- **极限 2 — 弱阻尼 γ₀≪ω₀ (Eq. 20):** `C(t) = (c₀²/2ζ)[(n_β+1)e^{-iζt} + n_β e^{iζt}]e^{-γ₀t}` → **Lindblad-伪模式基函数**
- **极限 3 — 过阻尼/Drude (Eq. 21):** `C(t) ≈ (c₀²/4γ₀)[cot(βω_D/2) - i]e^{-ω_Dt}` → **HEOM 标准化学物理模型**

### 方程 27-33 — Keldysh 框架构造 → Lindblad 形式

方程 27: `G(t) = [[G_K, G_R], [G_A, 0]]` (Keldysh Green 函数矩阵)
方程 28: `G_K(t) = (2n_ref+1)[G_R(t) - G_A(t)]` (Keldysh 分量)
方程 30: `K(i∂t) = [[0, i∂t-(ζ+iγ₀)], [i∂t-(ζ-iγ₀), 2iγ₀(2n_ref+1)]]` (逆核)
方程 31: `ϕ_{c/q}(t) = (1/√2)[ϕ_+(t) ± ϕ_-(t)]` (Keldysh 旋转)
方程 32: `ρ̂_s(t) = Tr_b{ρ̂(t)}` (偏迹)
方程 33: `ρ̇̂ = -iL₀ρ̂ + γ₀(n_ref+1)D[â]ρ̂ + γ₀n_refD[â†]ρ̂` (Lindblad 形式耗散)

### 方程 15 — 相关函数的指数分解形式（核心拟合形式）

```
C(t ≥ 0) = c₁ e^{-i(ζ-iγ₀)t} + c₂ e^{i(ζ+iγ₀)t}
```

复系数 c₁, c₂；实参数 ζ, γ₀。描述复频率 ±ζ-iγ₀ 位于复平面下半平面的阻尼模式。多指数推广直接（方程 15 文本）。

## 4. 为什么这对我们很重要

**这是为我们提出的"存储路线"(memory route) 提供统一理论锚点的论文**——通过伪模式将非马尔可夫共享 1/f/TLS 浴嵌入到扩展的马尔可夫空间中。

### 具体价值:

**1. 最优嵌入选择 + 误差分类，现成的。** 我们的源是结构化的洛伦兹/TLS 浴（二能级涨落器 ≈ 阻尼模式；1/f = 洛伦兹谱之和）。本文的最小物理模型**正是洛伦兹滤波-Ohmic 浴**（方程 18），其弱阻尼准热极限（方程 20）是 **Lindblad-伪模式基函数**——因此我们的浴完全处于本文的精确适用区间。

**2. Keldysh/三角 Lindblad-伪模式（方程 33）是我们馈入 CPTP 载体的正确嵌入。** 理由:
- 它为 `system ⊗ pseudomode` 产生一个**真实的 Lindblad 主方程**（即显式 CPTP 生成器）
- 每个洛伦兹峰对应一个具有 `γ₀(n_ref+1)` / `γ₀n_ref` 速率的额外阻尼玻色子模式
- 可以**直接馈入我们的 qutrit-MCWF-on-MPS 载波**（qutrit 需要 CPTP 生成器）
- 在长 QEC 周期下数值稳定（不同于 HEOM）

**3. 误差类是 (a) 精确的（对于多指数 `C(t)` 拟合）。** 唯一近似是相关函数拟合残差 + Fock 截断——这给预注册提供了清晰的认知论类阶梯:
- `C(t)` 拟合残差：如果我们控制拟合，则是 (a)-有界
- Fock 截断：声明 + 有界 (III) 简化，带收敛旋钮（提高维度）

**4. 保真度证书。** 高斯浴完全由 `C(t)` 确定（方程 2）。我们的源的基事实是浴相关函数——是一个**独立、闭式的真值**（满足 FAITHFULNESS_PROTOCOL 规则 I）：我们可以针对解析 `C(t)`/`J(ω)` 认证伪模式嵌入，而非针对另一个模拟器。

## 5. HEOM 对比 — 三角形 vs 块对角嵌入

| 对比维度 | Keldysh/三角嵌入 (Eq. 27-33) | 块对角/纯态嵌入 (Eq. 38-42) |
|---|---|---|
| **G(t) 结构** | 上三角，Keldysh + 推迟 + 超前 | 2×2 块对角（推迟, -推迟共轭） |
| **辅助初态** | 热态 `n_ref` | 真空 `|0⟩` |
| **读出示数** | 偏迹 (partial trace) | 真空投影 |
| **输出方程** | Eq. 33 (Lindblad 形式) | Eq. 42 (非对称双边形式) |
| **数值稳定性** | 稳定（有耗散项正则化） | γ₀=0 时不稳定（见 Ref. [65] 5.0节） |
| **与 HEOM 的关系** | n_ref=0 退化到 HEOM 结构 | 各种参数选择产生标准 HEOM |
| **表示依赖误差** | 截断在阻尼基中自然 | 截断效应敏感 |

### 为什么 HEOM 发散而 Lindblad-伪模式保持稳定

**根本原因 (§IV, 第 8-9 页; Ref. [65], Ref. [42]):**

1. **截断与变换不对易:** 块对角嵌入（方程 38-42）在 γ₀=0 极限下，辅助模式失去阻尼正则化 → 高阶 ADOs 携带的量子震荡未被耗散抑制 → 截断边界反射造成长期不稳定。

2. **Keldysh 嵌入的自稳定机制:** 方程 33 中的 Lindblad 耗散项 `γ₀(n_ref+1)D[â] + γ₀n_refD[â†]` 为辅助模式提供了**物理阻尼率 γ₀** → 高阶 Fock 态自然衰减 → 截断边界反射被指数压制。

3. **Bogoliubov 变换是救星:** 如 Ref. [65] 所示，对不稳定的块对角 HEOM 应用 Bogoliubov 变换（方程 43）映射到 Keldysh 框架 → 获得 Keldysh 框架的稳定性。类似地，方程 56-57 的 Nambu-Keldysh 变换在 Ref. [42] 中数值验证为稳定。

4. **论文的核心实践结论:** "截断的本征值谱是表示依赖的" → 选择正确的框架等效于将截断误差重新分布到动力学不重要的方向上 → **对长 QEC 周期模拟，选 Keldysh/伪模式框架（方程 33/57），不要用原始截断 HEOM**。

## 6. 局限性

### 明确局限性（作者声明）

- **高斯/玻色子浴 ONLY。** 整个构造假设线性耦合到由 `C(t)`（方程 2）完全刻画的高斯环境。非高斯浴、非简谐振子和非线性系统-浴耦合超出范围（非线性伪模式扩展仅被引用，Ref. [74]，未在此处发展）。

- **单系统算符 Ŝ，单（可分离）耦合。** 论文处理一个耦合算符 `ŜX̂_b(t)`。多算符/多站点耦合仅被**提及**为"可分离项之和"（方程 1 文本，Ref. [5]）——**未具体解决**。没有给出多量子比特/跨站点共享浴的构建；所有示例都是一个系统 + 一个辅助模式。

- **相关函数拟合是精度瓶颈。** 仅对多指数 `C(t)` 精确（方程 13）；一般浴 ⇒ 近似 ⇒ 需提高秩 K（更多伪模式）。**未证明**作为 K 函数的先验误差界或收敛定理——精度是"当 K 充分提高时可达到任意精度"。

- **玻色子 Fock 空间截断**是运行时成本和稳定性问题的源头；框架选择缓解但未消除。**无成本表/无基准**（纯理论）。

- **仅在 Brownian-振荡器/Lorentzian/Debye 族上演示。** 1/f 未直接处理；1/f 浴需要多洛伦兹（多伪模式）拟合。

### 对我们而言的关键局限

- **共享浴（多站点关联）未解决。** 我们的贡献楔子——跨量子比特共享的非马尔可夫相关浴——需要多算符耦合 `Σᵢ Ŝᵢ X̂_b`。论文仅给出单 `Ŝ` 构造并将多站点推迟到"可分离项之和"——**我们必须自己构建多站点扩展**（一个共享伪模式耦合到多个系统算符，或每对模式）。

- **截断 Liouvillian 谱是框架伪影。** 如果我们通过截断谱来认证嵌入，则该检查是**空洞的**（§IV）——除非与精确/框架不变谱相比较。

## 7. [ours] 章节 — 我们究竟在代码中使用哪个框架？

### 推荐框架: Keldysh/三角 Lindblad-伪模式（方程 33）

**选择理由:**

```
Keldysh/三角 Lindblad-伪模式 (Eq. 33)
    ↓ 产生
显式 CPTP Lindblad 生成器
    ↓ 馈入
qutrit-MCWF-on-MPS 载波 (quimb MPS, GPU-first)
    ↓ 执行
每个洛伦兹峰 → 一个阻尼玻色子模式
    ↓ 对非马尔可夫浴
多个模式堆叠为张量积伪模式
```

### 计算链

```
输入: 浴相关函数 C(t) 或谱密度 J(ω)
  │
  1. 将 C(t) 拟合为多指数和 (Eq. 15 形式)
     C(t≥0) = Σ_k c₁ᵏ e^{-i(ζᵏ-iγ₀ᵏ)t} + c₂ᵏ e^{i(ζᵏ+iγ₀ᵏ)t}
  │
  2. 每项构造 Keldysh 嵌入 (Eq. 27-30, 33):
     - 模式频率 ζᵏ, 阻尼 γ₀ᵏ
     - 参考占据 n_refᵏ (≈ Bose 分布 n_β 在准热极限)
     - 系统-模式耦合由 c₁ᵏ, c₂ᵏ 通过 U†_KP, V_KP (Eq. 29) 确定
  │
  3. 组装总生成器 L_sm:
     - 每个模式一个 Lindblad 耗散项 D[âᵏ] (速率 γ₀ᵏ(n_refᵏ+1), γ₀ᵏn_refᵏ)
     - 每个模式 -i[ζᵏâᵏ†âᵏ, ·] 自由演化
     - 系统-模式耦合项来自 Eq. 34 (L₀ 中的 Sq/Sc 耦合)
  │
  4. 嵌入到 MCWF-on-MPS:
     - 系统量子比特 (d=3 qutrit) + K 个玻色子模式 (每个截断到 Fock 维 D_k)
     - MPS 表示: (d^N × D₁ × D₂ × ... × D_K)-维张量网络
     - GPU-first 时间演化 (quimb TEBD/MPO)
  │
  5. 输出: 约化系统密度算符 ρ̂_s(t) = Tr_modes{ρ̂(t)}
```

### 回退选项（当需要最经济态空间时）

Hilbert-空间/单推迟格林函数嵌入（方程 47-52）：在辅助扇区使用纯态，`2K`-维希尔伯特空间。但失去显式 CPTP 保证。

### 应该避免的

**原始截断 HEOM（块对角嵌入，方程 38-42 不经 Bogoliubov 变换）**——在长 QEC 周期下已知不稳定 (Refs. [42,65,66,67])。

## 8. 可操作的实现路径

给定洛伦兹谱密度 `J(ω) = 4c₀²γ₀ω / [(ω²-ω₀²)² + 4γ₀²ω²]`，产生 GKSL 生成器 H, Γ 的步骤:

### 步骤 1: 计算相关函数参数

从谱密度提取:
- 有效振荡频率 `ζ = √(ω₀² - γ₀²)` (弱阻尼下 ≈ ω₀)
- 复系数 `c₁, c₂` (来自高温展开或精确拟合):
  - Case 2 (弱阻尼/准热, Eq. 20): `c₁ = c₀²/(2ζ) · (n_β + 1)`, `c₂ = c₀²/(2ζ) · n_β`, 其中 `n_β = 1/(e^{βζ}-1)`

### 步骤 2: 构造 Keldysh 嵌入参数 (Eq. 29)

自由参数: δ, λ (可取 δ=λ=1 的最简形式)
- `U†_KP = [[δ, δ(2n_ref+1) - (c₁*+c₂)/λ], [0, (c₁*-c₂)/λ]]`
- `V_KP = [[λ, 0], [(c₁+c₂*)/δ - λ(2n_ref+1), (c₁-c₂*)/δ]]`

简化条件: 当 `c₁*+c₂ ∈ R` 时，约束 `(2n_ref+1)δλ = c₁*+c₂` 消除非对角项。

### 步骤 3: 组装 GKSL 生成器

**自由哈密顿量部分:**
```
H_free = Ĥs + ζ â†â
```

**Lindblad 耗散项 (Eq. 33):**
```
Γ₁ = γ₀(n_ref+1)  → 坍缩算符 L₁ = â
Γ₂ = γ₀n_ref       → 坍缩算符 L₂ = â†
```

**系统-模式耦合 (Eq. 34, 取 δ=λ=1):**
```
H_coup = (U†_KP[0,0]·â_c + U†_KP[0,1]·â_q) + (V_KP[0,0]·â†_c + V_KP[1,1]·â†_q)
```
其中 `â_c = (â_+ + â_-)/√2`, `â_q = (â_+ - â_-)/√2`

等价地，在常规算符形式下 (Eq. 35 示例，准热极限):
```
H_coup = (c₀/√(2ζ)) Ŝ (â + â†)
```

**总生成器:**
```
L_sm ρ̂ = -i[H_free + H_coup, ρ̂] + γ₀(n_ref+1)(2âρ̂â† - {â†â, ρ̂}) + γ₀n_ref(2â†ρ̂â - {ââ†, ρ̂})
```

### 步骤 4: 多模式推广

对多洛伦兹拟合 `J(ω) ≈ Σ_k J_k(ω)`:
```
L_sm ρ̂ = -i[Ĥs + Σ_k ζ_k â_k†â_k + Σ_k g_k Ŝ (â_k + â_k†), ρ̂]
        + Σ_k [γ₀ᵏ(n_refᵏ+1) D[â_k] + γ₀ᵏ n_refᵏ D[â_k†]] ρ̂
```

### 步骤 5: 验证链

1. **C(t) 拟合验证:** `C_fit(t) = tr_b{ ⟨X̂b(t)X̂b†(0)⟩ }` vs 解析 `C(t)` (Eq. 15)
2. **嵌入验证:** 在精确 DM 模拟上运行嵌入 → `ρ̂_s(t)` 应与 Feynman-Vernon 影响泛函一致
3. **CPTP 验证:** 验证 Choi 矩阵的正性（自由参数 δ, λ 变化下的鲁棒性）
4. **Fock 收敛:** 扫描截断维度 D_k → 直到 `‖ρ̂_s(t; D)-ρ̂_s(t; D-1)‖ < NUMERICAL_ZERO`
5. **Bogoliubov 不变性 (可选):** 验证 `n_ref` 变化同时调整 δ, λ 保持 ρ̂_s(t) 不变（精确状态下）
