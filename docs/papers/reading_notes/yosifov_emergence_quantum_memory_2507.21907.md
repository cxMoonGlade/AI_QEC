## Executive summary [paper]

Establishes a **minimal criterion for when genuine quantum memory is required** to reproduce
non-Markovian dynamics, versus when classical memory suffices. The model is the QUANTUM
HOMOGENIZER — the paradigmatic collision model where a system qubit sequentially interacts
with ancilla reservoir qubits. The novel extension: intra-ancilla interactions mediated by
FREDKIN GATES (controlled-SWAP) generate non-Markovian system dynamics.

**Central finding — reservoir initialization entanglement structure is decisive:**

1. **GHZ-state reservoir initialization** → classical memory is sufficient. The reduced
   marginals of the reservoir are separable (no entanglement survives partial trace), and
   the global entanglement is only accessible through joint measurements across reservoir
   registers. Classical simulation of the system dynamics is possible.

2. **Bell-state reservoir initialization** → quantum memory is REQUIRED. The reduced
   marginals retain genuine quantum entanglement, meaning any classical simulation of the
   detector must maintain quantum correlations. This represents a fundamentally different
   resource requirement.

**The criterion:** Compare the Entanglement of Assistance (EoA) of the Choi state of the
unitaries C♯(Ũ) vs the Entanglement of Formation (EoF) of the Choi state of the channel
C(ℰ̃). When C♯(Ũ) < C(ℰ̃), the correlations in the channel exceed those that can be
generated by any local operation assisted by classical memory → quantum memory is
necessary.

**Activation lower bound:** Theorem providing the minimal dimension/size of ancilla system
below which quantum memory becomes necessary for the observed dynamics. This is the
concrete resource-counting result.

**Practical relevance:** "For realistic noise models involving asymmetric entanglement
in the reservoir, genuine quantum memory becomes essential" — i.e., most real quantum
environments require quantum memory, not classical, because their entanglement structure
is not of the globally-symmetric (GHZ) form.

## Key equations/findings [paper]

### Quantum homogenizer + Fredkin gate extension
The standard quantum homogenizer has sequential SWAP interactions between S (system qubit)
and each ancilla Aᵢ. The Fredkin extension adds controlled-SWAPs between ancillae:
Fredkin(Aᵢ, Aⱼ; control system). This correlates ancillae, producing non-Markovian
dynamics on S through intra-environment interactions.

### Memory classification criterion
Let Ũ be the unitary that generates the channel ℰ̃. Define:

- C♯(Ũ) = Entanglement of Assistance of the Choi state of Ũ
  (maximum entanglement that can be distilled from the state by local measurements and
  classical communication)
- C(ℰ̃) = Entanglement of Formation of the Choi state of the channel ℰ̃
  (minimal entanglement needed to create the state)

**Criterion:** If C♯(Ũ) < C(ℰ̃), then the channel correlations cannot be simulated by
any local operations assisted by classical memory → **genuine quantum memory required.**

### GHZ vs Bell initialization
- GHZ reservoir: ρ_anc = |GHZ⟩⟨GHZ|. Reduced single-ancilla states are maximally mixed
  (separable). All entanglement is global. Classical simulation of S dynamics is possible.
- Bell reservoir: ρ_anc = |Φ⁺⟩⟨Φ⁺|⊗ᴺ. Reduced two-ancilla states retain Bell
  entanglement → local operations on pairs require quantum memory.

### Activation bound
The minimum ancilla dimension d_min for which C♯(Ũ) < C(ℰ̃) becomes possible provides
a resource-theoretic threshold. Below this, all non-Markovian dynamics are classically
simulable regardless of coupling strength.

### Fredkin gate structure
Fredkin(Aᵢ, Aⱼ; c = system state) = if system is |1⟩, SWAP(Aᵢ, Aⱼ); else identity.
This creates intra-environment correlations that are CONDITIONAL on system state —
the system acts as a control for environment-environment couplings. This is the key
mechanism generating system-mediated environment correlations.

### Operational witness claim
The criterion can be evaluated using only LOCAL dynamics on the system — no full process
tomography needed. The Choi states of the unitaries/channels are constructed from the
system's time-evolved states under a complete basis of initial conditions.

## Relevance to project [ours]

**This is directly relevant to Claim 3 and the "is JC finite-γ memory classically
expressible or genuinely quantum?" question.** The connection runs through the
reservoir initialization:

### The JC model's vacuum initialization
The JC model has a single bosonic mode (cavity) initialized in VACUUM |0⟩. Vacuum is a
PRODUCT state — zero entanglement of any kind (no global, no local). This is
conceptually CLOSER to the GHZ case (where classical memory suffices) than the Bell
case (where quantum memory required), because:

- GHZ reservoir marginals are separable → classical simulation possible
- Vacuum reservoir is even simpler than GHZ — vacuum is a product state, while GHZ
  has global entanglement (albeit with separable marginals)

**Tentative implication:** The JC model at finite γ may indeed have classically-expressible
memory PRECISELY because the mode starts in vacuum. The user's observation that the
TV residual can be captured by a classical (hidden Markov) model would be consistent
with this: vacuum initialization ≈ GHZ-like regime ≈ classical memory sufficient.

### Where vacuum differs from GHZ
However, vacuum is NOT the same as GHZ:
- GHZ has GLOBAL entanglement but separable marginals
- Vacuum has NO entanglement at any scale
- The Yosifov criterion involves C♯(Ũ) vs C(ℰ̃) — for vacuum, both may be zero or
  near-zero, making the inequality C♯(Ũ) < C(ℰ̃) harder to satisfy
- Vacuum also has ZERO excitations — the JC dynamics then GENERATES entanglement
  as the mode becomes populated. The relevant question is whether the DYNAMICALLY
  GENERATED entanglement during the evolution suffices to require quantum memory

### Time-dependent entanglement structure
A crucial refinement: the reservoir's state EVOLVES during the interaction. The JC
mode starts in vacuum but acquires entanglement with the qubits as the evolution
proceeds. The Yosifov criterion is formulated for fixed reservoir initialization (the
ancilla state before interaction). For the JC model, we might need a TIME-DEPENDENT
extension: at what point in the evolution does the dynamically-generated entanglement
become sufficient to necessitate quantum memory? At finite γ (weak coupling), the
mode remains near-vacuum; at strong coupling, it becomes significantly populated.

### Fredkin gate vs JC mechanism
The Fredkin gate creates system-controlled environment-environment correlations. The JC
model's mechanism is different: a beam-splitter-type interaction H ∝ a†σ⁻ + aσ⁺.
There is no direct environment-environment coupling — correlations arise through the
shared system interaction. This is more analogous to the STANDARD quantum homogenizer
(sequential SWAPs) than the Fredkin-extended version. However: even for the standard
homogenizer with uncorrelated ancillae, memory can be non-Markovian but classically
expressible. The Fredkin extension is what CREATES the possibility of genuinely quantum
memory.

### Empirical prediction for the user's experiments
If the JC vacuum-initialized model has classically-expressible memory:
- The user's TV residual should be reproducible by a classical HMM with sufficient
  hidden states (which it apparently is — this is exactly what the user observes)
- Quantifying the entanglement of assistance of the dynamically-generated Choi state
  as a function of γ would provide a rigorous bound on when quantum memory becomes
  necessary
- This suggests a natural γ-threshold: below some γ_c, the dynamically-generated
  reservoir-state entanglement is below the threshold for quantum memory → classical
  expression is provably sufficient

### Yosifov as a falsification tool
The Yosifov criterion provides a PATH to falsifying the "classical memory" hypothesis:
- Compute the Choi state of the JC channel ℰ̃ (completely positive map on the system)
- Compute C♯(Ũ) and C(ℰ̃) for this channel
- If C♯(Ũ) < C(ℰ̃), then classical memory is PROVABLY insufficient
- If C♯(Ũ) ≥ C(ℰ̃), the dynamics COULD be classically simulated (but this doesn't
  prove they ARE — the classical model might still fail for other reasons)

This would be a decisive experiment: compute this criterion for the user's JC model
at the γ values where the TV residual is observed.

## Limitations

- **Qubit ancilla model:** the framework is built for qubit ancillae (each ancilla is a
  qubit). Extending to bosonic modes (infinite-dimensional Hilbert space) is non-trivial
  — the entanglement measures (EoA, EoF) are defined for finite-dimensional systems.
  A bosonic truncation (e.g., N-level approximation of the cavity) would be needed.

- **Single-mode vs multi-ancilla:** the JC model has a SINGLE bosonic mode (one "ancilla"),
  while the Yosifov model has MANY ancilla qubits. The "entanglement of the reservoir"
  in the JC case is between the mode and the system, not across reservoir partitions.
  The criterion of C♯(Ũ) vs C(ℰ̃) is system-only (doesn't need reservoir partitions),
  so this may not be a fundamental limitation.

- **Static initialization vs dynamic entanglement:** the criterion evaluates the reservoir
  state BEFORE interaction. The JC model's interesting behavior arises from the
  DYNAMICALLY GENERATED entanglement during evolution. The paper doesn't address
  time-dependent entanglement structure.

- **No analytical threshold:** the paper provides existence conditions but not a simple
  closed-form expression for the quantum-memory threshold as a function of coupling
  parameters. Practical computation requires solving for the Choi states.

- **Fidelity vs expressibility:** the paper addresses whether classical simulation is
  POSSIBLE in principle, not whether a specific classical model (e.g., the user's
  finite-state HMM) accurately captures the dynamics. Even if classical memory is
  sufficient, the user's specific classical model may still fail.
