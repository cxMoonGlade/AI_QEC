## 2. 核心方法——伪模式嵌入配方

### 2.1 原始模型 (Eq. 10-13)

考虑一个通过线性耦合与玻色子环境相互作用的系统：

**总哈密顿量** (Eq. 10):
```
H = H_S(Ω) + H_B + H_SB
```

- `H_B = Σ_k ω_k a_k† a_k` — 自由浴哈密顿量
- `H_SB = S ⊗ B` — 相互作用，其中 S = S† 是系统算符，`B = Σ_k g_k(a_k + a_k†)` 是浴算符
- 初始状态：`ρ_SB(0) = ρ_S(0) ⊗ ρ_B(0)`，浴处于高斯、平稳状态。不失一般性，取 `ρ_B(0) = |0⟩⟨0|_B`（真空），确保 `Tr(ρ_B(0)B) = 0`
- 系统希望估计的参数是 **Ω**（系统哈密顿量 H_S 中的频率参数），在处理后的相位为 φ = Ω·t

**约化动力学** (Eq. 11):
```
ρ_S(t) = Tr_B[ e^{-iHt} ρ_S(0) ⊗ ρ_B(0) e^{iHt} ]
```

由于浴初始为高斯且平稳，约化动力学完全由 **双时浴关联函数** 决定 (Eq. 12):
```
C(τ) = ⟨B(τ)B(0)⟩ = Tr(B(τ)B ρ_B(0))
```

其中 `B(t) = e^{iH_B t} B e^{-iH_B t}`。其傅里叶变换是 **浴谱密度** (Eq. 13):
```
γ(ω) = ∫_{-∞}^{∞} C(τ) e^{iωτ} dτ
```

### 2.2 极点-留数分解 → C(τ) 作为指数和 (Eq. 14) [核心配方步骤 1]

**关键假设**: γ(ω) 是亚纯函数（在复平面下半平面解析延拓后仅存在极点），且在 |ω|→∞ 时衰减快于 O(1/|ω|)。

应用留数定理，关联函数可写成 **有限指数和** (Eq. 14):
```
C(τ) = -i Σ_l r_l e^{-i z_l τ}
```

其中:
- `z_l = ξ_l - iλ_l` 是 γ(ω) 在下半平面的极点
- `r_l` 是相应的留数
- `λ_l > 0` 保证指数衰减（因果性）

**这是整个方法的基础**: 有限指数和意味着可以通过有限维的马尔可夫嵌入精确重构。

### 2.3 精确有限 Lindblad 主方程 (Eq. 15-22) [核心配方步骤 2-4]

**步骤 2**: 用 **伪模式** 替代原始浴。构建增广哈密顿量 (Eq. 15):
```
H' = H_S(Ω) + H_M + H_SM
```

其中:
- `H_M = Σ_l ξ_l b_l† b_l` — 伪模式自由哈密顿量（频率 ξ_l = Re(z_l)）
- `H_SM = S ⊗ Σ_l √(-i r_l)(b_l + b_l†)` — 系统-伪模式耦合（**相同系统算符 S 耦合到每个伪模式**）
- `√(-i r_l)` 被假定为实数以保证 H' 是厄米的
- 满足 `[b_k, b_l†] = δ_kl`

**步骤 3**: 每个伪模式 l 耦合到其自己的平坦马尔可夫剩余浴 R_l (Eq. 16-18):
```
H_SMR = H' + H_R + H_MR
```
其中 `H_R = Σ_l ∫ ω a_{Rl}†(ω) a_{Rl}(ω) dω`，`H_MR = Σ_l ∫ √(λ_l/π)[ b_l† a_{Rl}(ω) + b_l a_{Rl}†(ω) ] dω`。

**步骤 4**: 对 R 取迹后，联合 SM 系统服从精确马尔可夫 Lindblad 主方程 (Eq. 20-21):
```
d/dt ρ_SM(t) = ℒ[ρ_SM(t)] = -i[H', ρ_SM(t)] + ℒ_D[ρ_SM(t)]
```

其中 **耗散超算符仅作用在伪模式上** (Eq. 21):
```
ℒ_D[ρ_SM] = 2 Σ_l λ_l ( b_l ρ_SM b_l† - ½{b_l† b_l, ρ_SM} )
```

> **关键结构**: 原始系统 S **没有直接的 Lindblad 耗散项**。S 获得的退相干完全是通过与伪模式的幺正耦合"传递"过来的。这是伪模式嵌入的本质。

**步骤 5**: 选择 `ρ_SM(0) = ρ_S(0) ⊗ |0⟩⟨0|_M`（伪模式基态），约化系统动力学为 (Eq. 22):
```
ρ'_S(t) = Tr_M[ e^{ℒ t} ρ_S(0) ⊗ |0⟩⟨0|_M ]
```

**精确性声明**: 联合 S-M-R 系统的关联函数 C'(τ) 与原始 C(τ) 逐项匹配，因此 `ρ'_S(t) = ρ_S(t)`。需要 C(τ) 是有限指数和（即谱密度为有理函数/亚纯函数）。对于热浴等一般情况，只能 **近似拟合** C' ≈ C（参考文献 [54,61,62]，无先验误差界）。

### 2.4 用于计量学的有效通道 (Eq. 23)

对 ℒ 积分时间 Δt，得到有效参数依赖通道：
```
Λ_{Ω,Δt} = e^{ℒ Δt}
```
通过分割总传感时间 t = N·Δt，并在每步间施加量子控制，形成一个量子梳 Λ^{(N)}_{Ω,Δt}，其中 **伪模式空间 M 充当不可访问的记忆**，在控制步骤之间传递关联。

## 3. 量子计量学背景——量子梳和 QFI 优化 (Eq. 1-9)

### 3.1 量子 Cramér-Rao 下界 (Eq. 1)

对于无偏估计器 Φ̃，估计算子方差的下界：
```
Δ²Φ̃ ≥ 1 / F_Q(ρ_φ)
```
其中 F_Q(ρ_φ) 是输出态的量子 Fisher 信息。

### 3.2 量子梳表示 (Eq. 2-4)

一般 N 步自适应协议（图 2）被编码为一个量子梳 C（Choi 算符）：
```
C ∈ comb[(∅, H_1), (H_2, H_3), ..., (H_{2N-2}, H_{2N-1} ⊗ A_N)]
```
归一化条件（编码因果结构）：
```
C ⪰ 0,  C(0) = 1,  Tr_{2k-1}[C(k)] = 1_{2k-2} ⊗ C(k-1)  (Eq. 3-4)
```

N 个感知通道的联合作用也是量子梳 Λ^{(N)}_φ。输出态 `ρ^{(N)}_φ = C ⋆ Λ^{(N)}_φ`（链接积）。

### 3.3 ISS 优化 (Eq. 5-9)

QFI 优化通过 **预 QFI 函数** 的双重最大化实现 (Eq. 5-6)：
```
F(ρ₀, L) = 2 Tr(ρ̇_φ L) - Tr(ρ_φ L²)
F_Q(Λ_φ) = max_{ρ₀,L} F(ρ₀, L)
```

迭代 See-Saw (ISS) [42] 将问题分割为每一步的 SDP，并通过 **张量网络分解** 控制梳 C = C₁ ⋆ C₂ ⋆ ... ⋆ C_N (Eq. 9)，使用可控的低维辅助空间 d_A。这使得在大量 N 下可扩展优化成为可能。

## 4. CP 可分性破坏 (Eq. 22-24, 43-45) —— 非马尔可夫优势的根源

### 4.1 时间相关衰减率 γ(t) (Eq. 44)

对于 JC 实例，系统约化动力学可以写成含时 Lindblad 形式 (Eq. 43)：
```
ρ̇_S(t) = -i[Ω/2 σ_z, ρ_S(t)] + γ(t)( σ_- ρ_S(t) σ_+ - ½{σ_+ σ_-, ρ_S(t)} )
```
其中 (Eq. 44)：
```
γ(t) = 2γ_0λ sinh(dt/2) / [ d cosh(dt/2) + λ sinh(dt/2) ]
d = √(λ² - 2γ_0λ)
```

### 4.2 γ(t) < 0：CP 可分性破坏

| 条件 | γ(t) 行为 | CP 可分性 | 意义 |
|------|-----------|----------|------|
| γ_0/λ < 1/2（弱耦合） | 始终 > 0 | CP 可分 | 无真实非马尔可夫性；图 3b：无关联优势 |
| γ_0/λ > 1/2（强耦合） | 振荡，含负值区域 | **CP 不可分** | 非马尔可夫！图 3c：关联优势显著 |
| γ_0/λ = 1/2（临界） | d=0，γ(t)→γ_0 | 边界 | 过渡点 |

在 γ(t) 为负的时间区域，系统-浴信息流反转——浴将信息反馈给系统。这是 **关联噪声提升计量学精度的机制**。

> **关键观察**: 在特定时间，γ(t) 发散（Eq. 44 分母为零），此时按时序卷积展开的主方程不存在。这表明动力学具有真实的非马尔可夫性，不能由任何含时的局部主方程描述。

### 4.3 马尔可夫极限

在 λ ≫ γ_0（浴关联时间远短于系统时间）时：
```
c₁(t) ≈ c₁(0) e^{-γ_0 t/2}
```
动力学退化为具有恒定衰减率 γ_0 的标准马尔可夫振幅阻尼。在此极限下，关联环境和新鲜环境模型给出相同的 QFI（图 3b）。

### 4.4 非马尔可夫性在 QFI 中的体现

附录 A (Eq. A4) 给出无控制单步 QFI：
```
F_Q(t) = 4|c_0* c_1(t)|² t²
```

**QFI ∝ (相干性)²**，其中相干性由横向布洛赫半径 √(n_x²+n_y²) 给出。非马尔可夫动力学通过从浴中恢复信息来保持相干性，而新鲜环境模型始终失去相干性。这正是论文中关联模型优于新鲜模型的核心机制。

## 5. 关键警告——RWA 破坏的 n_max 成本

**这对我们的 QEC 模拟项目至关重要，也是论文留给未来工作的最大开放性成本问题。**

### 5.1 JC 耦合中的激发数守恒

JC 实例的相互作用是激发数守恒的 (Eq. 28)：
```
H_SB = Σ_k [ g_k(σ_+ ⊗ b_k) + g_k*(σ_- ⊗ b_k†) ]
```
总激发数算符 `N = σ_+σ_- ⊗ 1 + 1 ⊗ Σ_k b_k† b_k` 满足 `[H, N] = 0`。

因此，从真空态 `|0⟩_M` 出发，动力学始终停留在 **≤1 个总激发** 的 Hilbert 空间子空间内。这使得伪模式可以被精确截断为两能级系统（用 σ_± 替换 b₁, b₁†），得到 2-量子比特主方程 (Eq. 37-38)。

### 5.2 QEC 门破坏激发数守恒

论文明确指出 (p.6-7)：
> "in general, the control operations, applied on the system, in the most general adaptive metrological protocol, **may increase the total excitation numbers**"
>
> "in general, one might consider a larger-dimensional space M, where the dimension chosen would correspond to the **maximal number of additional excitation we want to take into account** as potentially appearing due to the applications of control operations"

论文将此推迟到未来工作：
> "Since the prime goal of this paper is to show how the method works, we will not aim here to push the numerical aspects of the problem to its limit. Hence, we will restrict ourselves to the simplest case where M is modeled as a two dimensional system and **leave the analysis of the more general scenario for the future work**."

**这对我们的影响**:

在我们的 QEC 设定中，典型门操作 **确实破坏激发数守恒**：

1. **CX (CNOT) 门**: 哈密顿量包含 σ_x ⊗ (1-σ_z)/2 + (1-σ_z)/2 ⊗ σ_x 项，其能级结构不是激发数保持的
2. **CZ 门**: 类似，对角项破坏激发数标记
3. **偏置旋转 Rx(θ), Ry(θ)**: 产生 |0⟩ 和 |1⟩ 之间的布居转移，破坏单激发子空间
4. **测量和复位**: 投影操作改变量子数

### 5.3 n_max 截断误差的标度

**论文没有提供明确的截断误差界**。这是我们需要自行推导的开放性理论问题。

**对于非激发数守恒的情况**，截断误差的标度依赖于反旋转项的相对强度：

- **RWA 有效的情况**（耦合强度 g ≪ 系统频率 ω₀）: 反旋转项 `σ_+ b₁†` 和 `σ_- b₁` 通过 ~g/ω₀ 的高阶过程贡献。此时 n_max = 2 可能足够（类似 Bloch-Siegert 位移的微扰处理）。
- **RWA 无效的情况**（g ≲ ω₀，强耦合/超强耦合）: 反旋转项直接产生多激发分量，截断必须包含所有重要虚拟过程。误差标度大约为 O((g/ω₀)^(n_max)) 在微扰理论中，但确切标度是模型依赖的。
- **我们的中间情况**（QEC 门耦合强度为 g，门操作时间 ~10-100 ns，ω₀ 在 GHz 范围）: g/ω₀ ~ 10⁻² 到 10⁻³，表明 n_max = 2-4 的截断可能足够，但 **这需要数值验证**。

**需要解决的具体问题**:
1. 对于线性耦合的 S⊗B 系统，其中 S 是跨多个量子比特的系统算子，耦合到单个伪模式：**截断玻色子空间的维数后，信道是否保持 CPTP？**
   - 回答：**是的**，如果截断是通过投影到有限维子空间后的 Lindblad 主方程实现的。截断本身会引入近似（丢失高频过程），但 CPTP 属性由 Lindblad 形式自动保证。
2. **截断误差如何随 n_max 变化？**
   - 误差主要来源于丢失的虚拟过程，涉及伪模式的高于 n_max 的能级。对于弱耦合，这通常可以控制。
3. 截断的伪模式是否适用于一般的非激发数守恒系统？
   - 这是一个开放数值问题，需要为我们的特定参数区域进行基准测试。

## 6. 与耦合-Lindblad 的关系

### 6.1 这是"单量子比特原始配方"吗？

**是的，这篇论文正是文献中耦合-Lindblad 公式所概括的"单探针原始配方"**，但需要明确两个独立发展方向的区别：

| 方面 | Das & Demkowicz-Dobrzanski (本文) | 耦合-Lindblad (多量子比特推广) |
|------|------|------|
| 系统 | 单探针 S（如 1 个量子比特） | 多量子比特 S = S₁ ⊗ S₂ ⊗ ... ⊗ S_n |
| 关联类型 | **时间关联**：浴记忆在时间步骤间传递 | **空间关联 + 时间关联**：共享浴 + 浴记忆 |
| 系统算符 S | 单个 S（如一个量子比特的 σ） | 集体 S = Σ_i S_i（多个系统算符求和） |
| 伪模式结构 | 所有 S 耦合到同一组伪模式 | 每个 S_i 可以耦合到同一组或不同组的伪模式 |
| 关联函数 | C(τ) = ⟨B(τ)B(0)⟩ — 单点 | ⟨B_i(τ)B_j(0)⟩ — 交叉点关联 |
| 论文是否涵盖？ | 全部 | **否** — 明确未完成（这仍然是"未来工作"） |

### 6.2 核心机制

两篇论文共享的核心机制是：**相同系统算符 S 耦合到有效浴**，其中浴的记忆通过伪模式（或一般地，通过有限维辅助系统）保留。区别仅在于 S 是单量子比特算子还是多量子比特集体算子。

Eq. 15 提供的推广钩子：
```
H_SM = S ⊗ Σ_l √(-i r_l)(b_l + b_l†)
```

将 S 替换为 Σ_i S_i（多个量子比特耦合到共享伪模式）即得跨多量子比特共享浴的集体 Lindblad 动力学。**这是论文没有采取但明确允许的步骤。**

### 6.3 耦合-Lindblad 需要增加的要素

相对于本文，耦合-Lindblad 推广需要：
1. **集体系统算符**: 用 `Σ_i α_i S_i` 替换单个 S
2. **交关联函数**: `⟨B_i(τ)B_j(0)⟩` 的空间关联结构
3. **CPTP 验证**: 确保集体嵌入保持完全正性（未经过明确推导，但应成立）
4. **相干性恢复特征**: 在空间关联噪声下，多量子比特相干性恢复的模式不同于单量子比特情况

## 7. [ours] 章节：我们的 QEC 浴关联函数需要什么

### 7.1 单量子比特 → 多量子比特推广的具体步骤

**步骤 A**: 确定 QEC 系统的浴关联函数

对于超导量子比特 QEC 系统，主要噪声源及其关联函数结构：
- **振幅阻尼 / 能量弛豫**: 关联函数 C(τ) = γ_0 e^{-λτ}（Lorentzian 谱）— 与 JC 模型相同
- **纯退相**: 关联函数 C_z(τ) = γ_φ e^{-λ_φ τ}（或 1/f 噪声，需要不同的处理）
- **串扰/寄生耦合**: 量子比特之间的非期望耦合，由共享环境中介

**我们需要确定**具体浴谱密度的形式。典型的超导量子比特环境：
- Ohmic 浴：J(ω) ∝ ω exp(-ω/ω_c)。**问题**：Ohmic 谱不是亚纯函数 → 不能精确表示为有限指数和。需要近似拟合，截断低频部分。
- 1/f 噪声：J(ω) ∝ 1/ω。**同样非亚纯**。需要用 Lorentzian 峰叠加来近似 [54,61,62]。
- 结构化的 TLS 环境：一系列离散的 Lorentzian 共振 → **亚纯 → 精确表示**。

**步骤 B**: 多量子比特推广的形式

推广 Eq. 15 到多个量子比特：
```
H_SM = Σ_i S_i ⊗ Σ_l √(-i r_l) (b_{i,l} + b_{i,l}†)
```

其中 S_i 作用于量子比特 i，而 b_{i,l} 是量子比特 i 对伪模式 l 的耦合。如果所有量子比特共享相同的浴，则 b_{i,l} = b_l 对所有 i 相同：
```
H_SM = (Σ_i S_i) ⊗ Σ_l √(-i r_l) (b_l + b_l†)
```

**这正是我们称之为"共享浴集体 Lindblad"的结构。**

**步骤 C**: 交关联函数的确定

对于两个量子比特 i 和 j，它们与同一个伪模式耦合：
```
⟨B_i(τ) B_j(0)⟩ = Tr[ B_i(τ) B_j ρ_B(0) ]
```

在共享浴模型中，若两个量子比特以不同耦合强度 g_i, g_j 耦合，则交关联与自关联的比值为 g_i g_j / (g_i² + g_j²)。**这需要根据物理环境具体参数化。**

### 7.2 我们需要的具体能力

1. **浴编辑能力**: 根据设定的谱密度 J(ω) 产生对应的 H_SM 和 ℒ_D
2. **多量子比特集体耦合**: 支持 S → Σ_i S_i 形式的系统算符
3. **可调 n_max 截断**: 支持每个伪模式截断到 ≥2 个能级
4. **通道组装**: 从增广 Lindbladian ℒ 产生通道 e^{ℒ Δt} 并约化到系统
5. **相干性探针**: 检测多量子比特自旋回波/动力学去耦等协议下的相干性恢复

### 7.3 验证策略

论文提供了一个重要的独立预言 (Eq. 40-45)，可以用于验证我们的实现：

1. **单量子比特情况**: 实现伪模式嵌入 → 积分 Lindblad 方程 → 对 M 取迹 → 对比 Eq. 40 的 c₁(t) 解析解。这满足 Faithfulness Protocol 的 Rule I（独立闭式预言）。
2. **多量子比特情况**: 验证在去耦极限（λ ≫ γ₀）下约化为标准马尔可夫多量子比特动力学。
3. **CP 可分性破坏检测**: 验证在 γ₀/λ > 1/2 下 γ(t) 呈负值振荡。
4. **n_max 收敛测试**: 对于非激发守恒算符，验证 Fock 截断在增加 n_max 时的收敛速度。

## 8. 可操作的实现路径

给定谱密度 J(ω) ≡ γ(ω)（或等价地，关联函数 C(τ)），以下是产生 H_S 和 ℒ_K（L_k 算符）的完整步骤序列：

### 步骤 A：极点-留数提取

```
输入: γ(ω) — 浴谱密度（亚纯，|ω|→∞ 时 < O(1/|ω|)）
输出: {z_l, r_l} — 极点-留数对集合

操作:
1. 解析延拓 γ(ω) 到下半复 ω 平面
2. 找到所有极点 z_l = ξ_l - iλ_l (λ_l > 0, 因果性)
3. 计算每个极点的留数 r_l
4. 验证: C(τ) = -i Σ_l r_l e^{-i z_l τ} 收敛为实际关联函数
```

### 步骤 B：伪模式映射

```
对于每个极点 z_l = ξ_l - iλ_l 及留数 r_l:

1. 创建玻色子模式 b_l, b_l†
2. 自由哈密顿量: H_M += ξ_l b_l† b_l
3. 系统-伪模式耦合强度: g_l = √(-i r_l) [确保实值; 若为复值参见注]
4. 系统-伪模式耦合: H_SM += S ⊗ g_l(b_l + b_l†)  [S 是系统算符]
5. Markovian 阻尼率: γ_l = 2λ_l
6. 耗散超算符: ℒ_D += γ_l (b_l · b_l† - ½{b_l† b_l, ·})
```

**对于多量子比特推广**: 将 `S ⊗ g_l(b_l + b_l†)` 替换为 `(Σ_i α_i S_i) ⊗ g_l(b_l + b_l†)`，其中 α_i 是各量子比特的耦合权重。

### 步骤 C：截断

```
对于每个玻色子模式 b_l:
  从无限维 Fock 空间截断到 {|0⟩, |1⟩, ..., |n_max-1⟩}
  其中 n_max ≥ 2（对于激发守恒）。对非守恒情况，n_max 需要在数值上收敛。

  替换:
  b_l → Σ_{n=0}^{n_max-2} √(n+1) |n⟩⟨n+1|
  b_l† → Σ_{n=0}^{n_max-2} √(n+1) |n+1⟩⟨n|
  b_l† b_l → Σ_{n=0}^{n_max-1} n |n⟩⟨n|
```

### 步骤 D：增广 Liouvillian 构建

```
联合空间维度: d_tot = dim(H_S) × Π_l n_max,l

1. 构建 H' = H_S(Ω) + H_M + H_SM (在增广空间中)
2. 构建 ℒ_D (在增广空间中)
3. 组合: ℒ[ρ] = -i[H', ρ] + ℒ_D[ρ]
4. 积分: Λ_{Ω,Δt} = exp(ℒ Δt) [矩阵指数; 需要向量化]
```

### 步骤 E：约化到系统

```
给定初始状态 ρ_SM(0) = ρ_S(0) ⊗ |0⟩⟨0|_M:

1. ρ_SM(Δt) = Λ_{Ω,Δt}[ρ_SM(0)]
2. ρ_S(Δt) = Tr_M[ρ_SM(Δt)]
```

### 步骤 F（可选）：近似拟合

对于非亚纯谱密度（如 Ohmic、1/f）：

```
1. 选择一组伪模式参数 {ξ_l, λ_l, g_l} 使得:
   C'(τ)= -i Σ_l r_l e^{-i z_l τ} ≈ C(τ)
2. 拟合通过最小化: ∫|C(τ) - C'(τ)|² dτ (参考文献 [54,61,62])
3. 重要: 这种近似没有先验误差界——只能通过自洽性检查验证
```

## 10. 限制与开放性理论问题

### 论文本身的限制

1. **单探针**: 只有一个二能级系统；没有多量子比特，没有空间关联
2. **单伪模式，截断到 2 能级**: "主要目的是展示方法…不会把数值问题推到极限"
3. **只考虑玻色子、高斯、平稳、真空浴**: 激发守恒（旋转波）相互作用是精确 JC 解所必需的（Eq. 28）
4. **精确嵌入需要 C(τ) = 有限复指数和**: 热浴/一般浴只有近似拟合 C'≈C，**无先验误差界**
5. **无大规模基准**: 论文只运行了小的 N，S⊗M = 2 量子比特。无大量 N 或多伪模式基准；无墙钟时间

### [ours] 开放性理论问题

1. **截断误差的严苛界**: 当激发数不守恒且 n_max 有限时，信道 2-范数或 diamond 范数误差 ∥Λ_exact - Λ_trunc∥_◇ 如何标度？（论文未回答，需要我们的分析）
2. **集体 S→ΣS_i 推广的 CPTP 保持**: 将相同系统算符替换为求和形式是否总是保持 CPTP？（期望是肯定的，但需明确验证）
3. **共享浴交关联函数**: 我们的具体噪声模型需要什么样的 ⟨B_i(τ)B_j(0)⟩ 结构？（模型依赖，需要从物理环境构建）
4. **非亚纯谱密度的最优拟合**: Ohmic/1/f 谱应采用多少伪模式？拟合误差的有界性如何？
5. **QEC 门下的相干性恢复特征**: 多量子比特共享浴模型在 QEC 门操作下是否仍然表现出相干性恢复特征？该楔是否在 CP 可分极限（γ₀/λ < 1/2）下消失？[来自 project-nonmarkovian-wedge-must-be-coherence]
6. **嵌入计算成本**: 对于 d 个量子比特和 p 个伪模式（每个截断到 n_max），增广希尔伯特空间维数为 2^d × n_max^p。对于 d=3 表面码，如果 p=1, n_max=2，则有 8×2=16 维。但如果 d=17 表面码且 p=2, n_max=4，则为 2^17×4²=131072×16≈2×10^6——仍在可控范围内，但必须考虑 GPU 路由。

## 11. 与 qec_twin 的相关性和可复用性

### 关键结论

**这篇论文没有展示我们需要的跨量子比特共享浴伪模式嵌入。** 它的"关联"是时间性的（单传感器的时序记忆）而非空间性的。这正是旧共享浴论文中保留的"未来工作"，在这篇论文中仍然有待完成。

但它为我们的实现提供了三个高价值的可复用组件：

1. **极点→伪模式→精确 Lindblad 配方（Eq. 14-21）是正确的嵌入原语。** 它通过有原理依据的方法、而非临时捏造的 TLS 构建了记忆核心。
2. **推广钩子是显式的（Eq. 15）**：用 Σ_i S_i 替换 S 恰好产生跨多量子比特的共享浴集体 Lindblad——这正是我们笔记要求的"将 SOURCE 显式地作为正速率集体 Lindbladian 携带"。
3. **CP 可分性/相干性恢复是可认证的特征。** 论文将非马尔可夫性操作化为 γ(t) 变负（γ₀/λ>1/2），并展示了计量学收益居于 *相干性* 中——直接支持我们的论断：不可伪造的楔是相干性恢复（|L(t)| 非单调），而不是经典圆关联。
