## 2. 核心方法 (Core Method)

### 2.1 过程张量作为多时间量子梳 (Process Tensor as Multi-Time Quantum Comb)

**Choi-Jamiolkowski 同构 (Choi 表示).** 所有对象均以 Choi 态 / 双狄拉克 (double-ket) 形式表示:

- 向量化: `vec(|ψ⟩⟨ϕ|) = |ψ⟩ ⊗ |ϕ*⟩` (Eq. 4). 一个量子通道 `E` 作用在 `|ρ⟩⟩` 上如同矩阵乘法 (Eq. 7-8).
- Choi 态: `Υ_E = (E ⊗ I)[|Φ+⟩⟨Φ+|] = Σ_{ij} E[|i⟩⟨j|] ⊗ |i⟩⟨j|` (Eq. 9). Choi 态 `Υ_E` 与通道 `E` 一一同构.
- 通道作用的 Choi 形式: `Ě|ρ⟩⟩ = vec(tr_i[(1_o ⊗ ρ^T)Υ_E]) = _i⟨⟨ρ*|Υ_E⟩⟩_o` (Eq. 10).
- 量子仪器 (instrument): `J = {A_j}`, `ρ'_j = A_j[ρ] = Σ_α K_{α,j} ρ K†_{α,j}`, `P(j|J) = tr(A_j[ρ])` (Eq. 12). Choi 形式: `P(j|J) = ⟨⟨A*_j|1⟩⟩_o ⊗ |ρ⟩⟩_i` (Eq. 14).

**过程张量定义.** 对于 k 步过程, 给定控制操作序列 `A_{xT_{k-1}} = {A_{x0}, ..., A_{x_{k-1}}}` (仅作用在系统 S 上), 系统的输出态为:

`ρ[A_{xT_{k-1}}] = tr_E[ ⃝_{j=0}^{k-1} U_j ∘ A_{x_j}(ρ_SE(0)) ] =: Υ_{T_k}[A_{xT_{k-1}}]` (Eq. 17)

核心结构: **CP 映射 A_j 只作用在系统 S 上, 但插入的酉门 U_j 作用在 S 和环境 E 上** —— 对 E 取迹后留下时间关联. 因此 Υ 是一个多时间量子梳 (multi-time quantum comb), 携带浴的记忆效应跨步骤传播.

**概率与状态提取.** 将 Υ 与仪器序列 `A_{xT_k}` 收缩:

`P(xT_k|JT_k) = tr[Υ_{T_k}[A_{xT_k}]] = ⟨⟨1_{o_k}|Υ_{T_k}[A_{xT_k}]⟩⟩` (Eq. 20)

`|ρ(t_k|xT_{k-1}, JT_{k-1})⟩⟩ = ⟨⟨A*_{xT_{k-1}}|Υ_{T_k}⟩⟩` (Eq. 22)

**Tester (相关仪器).** 一个 tester 是带有记忆的仪器, 其 Choi 态可以写为:

`A_{xT_k} = Σ_{xT_k} α_{xT_k} ⨂_{j=0}^{k} \hat{A}_{x_j}` (Eq. 23)

其中系数 `α_{xT_k}` 可以是任意的 (甚至非正). Tester 正是量子纠错中前馈式症候测量 → 恢复操作的形式化描述.

### 2.2 链接积收缩: 张量网络解码器的核心操作 (Link-Product Contraction)

**链接积 (Link Product, ⋆).** 定义于 Ref. [42, 20], 是 Choi 态层面的通道级联操作. 若 A 和 C 分别是通道 `A` 和 `C` 的 Choi 态, 则 `D = C ⋆ A` 是级联通道 `C ∘ A` 的 Choi 态. 在 TN 图形化表示中, ⋆ 对应连接匹配的输入/输出腿并求和 (即张量缩并).

**QEC 作为一个大型 Tester.** 症候测量 (stabilizer generator G_j 的投影测量) 的仪器形式:

`J_j = {π_{x_j} = (1 + (-1)^{x_j} G_j)/2}`, `Π_{x_j}(•) = π_{x_j} • π_{x_j}` (Eq. 25-26)

整个 (症候测量 + 恢复) 对构成一个大型 tester:

`C_{xT_{1:n-k}} = Σ_{x'} Π_{xT_{1:n-k}} ⊗ R(x'_T) δ_{x, x'}` (Eq. 30/37)

**这其中的 Kronecker δ 是关键:** 它连接了测量结果和恢复操作的经典前馈关联. 过程张量的时间关联通过 Υ 流动, 而 tester 的 δ 将恢复选择绑定到 Υ 实际产生的结果上.

**编码/解码通道.** 编码映射 `E_enc: H_logical → H_o` 的投影器:

`Π_enc = |ψ_{L,0}⟩⟨0_L| + |ψ_{L,1}⟩⟨1_L|` (Eq. 38)

解码映射 `E_dec(•) = Π†_{enc} • Π_{enc}` (Eq. 40)

### 2.3 LER 从单次收缩中得出: 方程 45/49 的工作原理 (LER from Single Contraction)

**这是本文最核心的贡献之一: 逻辑失败率 (LER) 通过单次张量网络收缩计算, 而非蒙特卡洛模拟.**

**HS 度量 (内积, Eq. 43-45):**

`χ_HS(L, ⃗s) = ⟨⟨Π_dec ⋆ I ⋆ [C_{Lpdc,spdc}] ⋆ Υ_{T_{n-k+1}}[C_{L,⃗s}] ⋆ Π_enc | Υ_1⟩⟩` (Eq. 43)

这是整个战略码过程 (编码 → 含噪 Υ → 症候测量 → 恢复 → *完美*的第二轮症候+解码) 与逻辑恒等通道的 Hilbert-Schmidt 重叠.

- `L̄(⃗s) = argmax_L χ_HS(L, ⃗s)` (Eq. 44)
- `p_fail = 1 − Σ_{⃗s} χ_HS(L̄(⃗s), ⃗s)` (Eq. 45)

**CD 度量 (通道距离, Eq. 46-49):**

`χ_CD(L, ⃗s) = ‖ Π_dec ⋆ I ⋆ [C_{Lpdc,spdc}] ⋆ Υ_{T_{n-k+1}}[C_{L,⃗s}] ⋆ Π_enc − Υ_1 ‖_2` (Eq. 47)

`L̄(⃗s) = argmin_L χ_CD(L, ⃗s)` (Eq. 48)

`p_fail = Σ_{⃗s} p(⃗s) χ_CD(L̄(⃗s), ⃗s)`, 其中 `p(⃗s) = tr[ρ_L Π^T_enc Π^T_⃗s Υ]`, `ρ_L` 是逻辑 qubit 上的完全混合态 (Eq. 46, 49).

**为何是单次收缩:** 整个 TN (Fig. 8b) 对**所有**症候 `⃗s ∈ {0,1}^{n−k}` 和**所有**逻辑操作 L 一次性给出成功概率矩阵. 求和 `Σ_{⃗s}` 是对这个矩阵的简单后处理, 不需要对每个 ⃗s 分别模拟. 这使得 LER 计算从 O(2^{n−k} × 蒙特卡洛样本量) 降低为 O(一次 TN 收缩).

**结构解读 (Fig. 8b):** TN 顺时针流动: ENCODER → 过程张量 Υ (携带浴) → 症候测量仪器 → 恢复操作 (PURE ERROR + LOGICAL OP) → 链接到完美第二轮 (I 过程张量 + 完美症候 + 恢复). 输入-输出腿通过最大纠缠态缝合. 编码器和解码器腿被合并为 ENCODER 张量以减小尺寸.

### 2.4 MPS 对过程张量的近似 (MPS Approximation)

**状态向量成本.** 在本文的模型中 (n 数据量子比特 + n 浴量子比特 + k 经典比特 + 1 辅助量子比特), 状态向量模拟的内存成本为:

`4^{2n+1} × 2^k`

对于 Steane 码 (n=7, k=6): `2^36` —— 需要 HPC. 这是精确方法的现实上限 (仅 d=3 小码可行).

**MPS 方法.** 将过程张量 + tester 表示为 MPS, 索引顺序为:

`[auxiliary | data_1 bath_1 data_2 bath_2 ... data_n bath_n | classical bits_1 ... classical bits_k]` (Fig. 10b)

- 初始态 `|Π_enc⟩⟩` 用 MPS 表示.
- 噪声和 stabilizer 测量都是 MPO, 通过 MPO-MPS 演化推进.
- 最大键维数 D = χ, 超过的通过 canonical form 截断; 同时对低于阈值 (10^{-8}) 的奇异值进行动态截断 (Table 2).
- 结束时对浴 qubits 取迹, 得到过程张量 + tester 的 MPS 近似 `Υ̃`.

**BEE 诊断 (Fig. 11).** 双粒子纠缠熵 (Bipartite Entanglement Entropy) 用于诊断截断安全性:

- **量子系统内平均 BEE:** 在低噪声下很大 (因为逻辑 Bell 对是等权重叠加态, 需要精确表示).
- **量子与经典系统间 BEE:** 在低噪声下很小 → 症候分布有偏 → MPS 可以自动截断极不可能出现的症候模式.
- 这表明将经典比特放在 MPS 末端是合理的, 在低噪声下额外计算成本较低.

**两个评价指标 (Eq. 54-56):**

| 指标 | 含义 | 计算公式 |
|---|---|---|
| `p_est` (估计 LER) | 使用近似 `Υ̃`, `p̃` 同时构建解码器并评分 | `p_est = Σ p̃(⃗s) min_L ‖Q(L,⃗s) ⋆ Υ̃[Π(⃗s)] ⋆ Π_enc/p̃(⃗s) − I‖_2` (Eq. 54) |
| `p_perf` (TN 解码器性能) | 解码器 `L̃` 从近似 `Υ̃` 选取, 但评分使用**精确** `Υ` | `p_perf = Σ p(⃗s) ‖Q(L̃(⃗s),⃗s) ⋆ Υ[Π(⃗s)] ⋆ Π_enc/p(⃗s) − I‖_2` (Eq. 55-56) |

`Q(L,⃗s)` (Eq. 53) 是解码器侧张量, 不含浴系统, 对给定的 QEC 码只需构建一次, 与噪声模型无关. `p_est` 和 `p_perf` 的分离是为了区分"近似误差对 LER 估计的影响"和"近似解码器的性能损失".

## 3. 噪声模型 (Noise Model, Eq. 50-52)

噪声模型定义于 §4.1, Fig. 7 示其结构. 每步 `k`, 对每个数据量子比特 `i` 顺序应用三种错误机制:

### 3.1 去极化: iid 基线 (Eq. 50)

```
E_dep(ρ, p_err) = (1 − p_err)ρ + p_err Σ_{σ∈{X,Y,Z}} σρσ†
```

- 这是标准 iid Markovian 噪声.
- **注意:** 这是 3p 约定: `p_err` 权重施加于 X/Y/Z 每个 Pauli, 错误发生总概率为 `3·p_err`.
- 参数扫描范围: `p_err ∈ [10^{-6}, 10^{-1}]`.

### 3.2 非马尔可夫浴: 私有浴 XX+YY+ZZ 耦合 (Eq. 51)

```
U_NM := exp{−i J_NM (X_i X_{B_i} + Y_i Y_{B_i} + Z_i Z_{B_i})}
```

- 每个数据量子比特 `i` 拥有**自己的局部浴量子比特** `B_i`.
- `U_NM` 是一个 Heisenberg 耦合 (XXX+YYY+ZZZ, 即各向同性交换相互作用), 纠缠数据量子比特和其私有浴.
- **私有浴跨步骤保留 (不重置)**, 因此产生**时间上的 (非马尔可夫) 关联** —— 这是本文负载性的"记忆"成分.
- **关键限制 [ours]:** 每个浴是私有的 ⇒ 产生的是**逐量子比特的时间关联**, 而非共享浴导致的交叉量子比特非马尔可夫关联. 这与我们 coupled-teacher 中共享潜变量 (shared latent bath) 的目标不同.
- 参数: `J_NM ∈ {0, 10^{-4}, 10^{-3}, 10^{-2}, 10^{-1}}`.

### 3.3 相干 ZZ 串扰: 空间相关性 (Eq. 52)

```
U_CT := exp{−i J_CT Z_i Z_{i+1}}
```

- 相邻数据量子比特之间的 ZZ 耦合.
- **纯酉 (coherent), 无浴**, 因此不引入额外的退相干 —— 只是"重新排列"量子信息.
- 产生**空间上的**相关性, 但不产生时间关联.
- 参数: `J_CT ∈ {0, 10^{-4}, 10^{-3}, 10^{-2}, 10^{-1}}`.
- Fig. 9c 使用 `p_err = 10^{-3}` 固定, `J_NM × J_CT` 热力图显示相关噪声的联合效应.

**每步的综合结构 (Fig. 7):** 每个时间步 `k`, 每个数据量子比特 `i` 依次经历: `E_dep → U_NM → U_CT` (对相邻量子比特). 所有 B_i 浴量子比特跨步骤保留, 在最终取迹.

## 4. 解码器性能 (Decoder Performance)

### 4.1 PT 感知型 ML 解码器对比 MWPM —— 本文未做此比较

**这是本文最重要的缺失项 (关键局限性).** 本文构建的解码器始终是过程张量感知的 ML 解码器. "改进"被测量为 `p_fail(J > 0) − p_fail(J = 0)` 在**同一最优解码器**下的差值, 即:

- 它测量的是**相关性噪声的内禀惩罚 (intrinsic noise penalty)**, 而非"PT-aware 解码器优于不匹配的 Markov 解码器"的程度.
- 本文**没有**与 MWPM 或 Pauli 解码器的头对头比较.
- 这意味着**Kam 等人的 "syndrome-correlation 可被 Markov-k 捕获" 的论断未被直接反驳**. 如果有问题的非马尔可夫性完全体现在症候统计中, 一个 Markov 解码器 (如 MWPM) 可能已经接近最优.

**对我们 [ours] 的影响:** 这正是我们需要填补的空白. 我们的 headline 指标应该是:

`ΔLER = LER(不匹配的 Markov 解码器) − LER(PT 感知的 ML 解码器)`

即, PT-aware 解码器相对于 Markov 解码器在非马尔可夫噪声下的**额外改进**.

### 4.2 本文已测量的数值结果

**五量子比特码 (Fig. 9), 单轮:**
- 即使 `J_NM = J_CT = 0`, `p_fail` 非零 —— 因为单轮含噪声症候测量下, 在测量之后发生的错误会被遗漏.
- **NM 和 CT 都提高 p_fail** (Fig. 9a/b). NM 增加实噪声 (信息泄露到浴), CT 是酉的但"扰乱信息"也降低 LER.
- **出现阈值 (Fig. 9c, p_err=10^{-3} 固定):** NM 和 CT 效应在 `J ≈ 10 × p_err` 时突然显现. 这意味着相关性噪声的惩罚在耦合 ≳ 10·p_err 时开启.

**Steane 码 + MPS (Table 2), 单轮:** 精确 TN 结果与 MPS 近似对比:

| 噪声 (p_err=J_CT=J_NM) | 精确 p_fail | MPS χ=128 | MPS χ=1024 | 1−F @χ=1024 | 时间 χ=1024 vs 精确 |
|---|---|---|---|---|---|
| 10^{-4} (低) | 8.083e-4 | p_est 6.27e-4 / p_perf 9.03e-4 | ~8.08e-4 | 4.1e-13 | 199s vs 532s (MPS 更快) |
| 10^{-3} (中) | 8.691e-3 | 6.74e-3 / 9.63e-3 | 8.691e-3 | 1.1e-12 | 1320s vs 532s (MPS 更慢) |
| 10^{-2} (高) | 1.355e-1 | 1.15e-1 / 1.43e-1 | 1.355e-1 | 5.6e-7 | 6378s vs 532s (MPS 大幅更慢) |

**关键发现:**
- **低噪声:** 即使 χ=128 也能接近精确, 且比精确更快 (63s vs 532s @10^{-4}). MPS 是真正的胜利.
- **高噪声:** MPS 需要大 χ, 在 χ=1024 时 ~12× 慢于精确 —— 近似不再值得.
- **NM 是最难的:** "在非马尔可夫噪声强的区域, 性能明显下降", 而强去极化/CT 不退化 TN 解码器性能. 非马尔可夫性正是膨胀纠缠度/键维数的成分.

### 4.3 两个度量的行为差异

- **HS 度量 (Eq. 43, 实线)** vs **CD 度量 (Eq. 47, 虚线)** (Fig. 9a/b). 两者定性趋势一致但不重合.
- 在 `J_NM` 或 `J_CT` 很大时, CD 度量给出的 p_fail 通常高于 HS 度量 —— 因为 CD 捕捉了相干/非对角项, 而 HS 忽略它们.
- **但两者差距不大 (同一数量级),** 可能是由于去极化噪声主导了错误率.

## 5. 关键局限性 (Critical Limitations)

这些局限性对 qec_twin 构成了关键的边界条件, 我们在复用本文方法时必须逐一解决.

### 5.1 每个量子比特的私有浴 —— 无共享潜变量/交叉量子比特关联

- Eq. 51 的 `U_NM` 中每个数据量子比特 `i` 有自己的私有浴 `B_i`. 不同浴之间**不相互作用**, 也不共享.
- 这意味着非马尔可夫关联是**逐量子比特的**: 时间关联存在, 但交叉量子比特的非马尔可夫关联不存在.
- 相比之下, 我们的 coupled-teacher 需要**共享浴 (shared bath)** 或**共同潜变量 (common latent variable)**, 以产生跨量子比特的空间-时间关联 (例如, 一个 fluctuating two-level-system 同时影响多个量子比特).
- **需要修改 [ours]:** 将私有浴替换为共享浴架构, 或添加浴-浴相互作用.

### 5.2 HS 度量是相干盲的 (Eq. 43); CD 度量能捕捉相干性但不是严格概率

- HS 度量 (Eq. 43) 仅测量逻辑通道与恒等通道的 Hilbert-Schmidt 内积: `⟨⟨Π_dec ⋆ I ⋆ ... | Υ_1⟩⟩`. 这**忽略逻辑通道的非对角/相干项** —— 论文明确指出了这一限制.
- CD 度量 (Eq. 47) 使用 Frobenius 范数: `‖ ... − Υ_1 ‖_2`, **确实看到相干性**, 但 "cannot satisfy the strict axioms of probability" (论文的警告). 它给出的 `p_fail` 不是严格概率.
- **对我们 [ours] 的意义:** 如果我们的非马尔可夫楔形 (non-Markovian wedge) 携带相干性, HS 度量会**低估**其效应. 我们需要使用 CD 度量或 diamond distance 作为辅助指标.
- 论文未运行 diamond distance [44] 尽管提到了它是可能的指标.

### 5.3 仅小代码: [[5,1,3]] 和 [[7,1,3]], 非表面码

- 仅 d=3, k=1. 状态向量成本 `4^{2n+1} × 2^k` → 对 Steane 已是 2^36.
- 无 d>3 缩放研究, 无表面码.
- 这限制了关于"非马尔可夫噪声对不同距离码的影响如何缩放"的任何结论.
- **对我们的约束:** 表面码 d=3 的 TN 已经比 Steane 大得多; d=5 需要更激进的近似.

### 5.4 单轮, 非多轮

- 论文明确在结论中说: "Our construction of the ML decoder treats just single round syndrome measurement."
- 单轮下即使 J=0 也有非零的 `p_fail`, 因为测量之后发生的错误无法检测. 这是单轮假象, 不是非马尔可夫效应.
- 多轮症候测量 (space-time decoding) 被列为未来工作, 并会大幅增加 TN 大小.
- **对我们 [ours]:** 多轮是现实的必需; 我们的 frozen-MWPM (时间匹配) 指向多轮解码.

### 5.5 未与 MWPM 进行比较

- 这是本文最关键的缺失 —— 论文**从未将一个不匹配的 Markov 解码器**放在相同噪声下进行比较.
- 因此我们不知道 PT-aware ML 解码器相对于实际可用的解码器 (如 MWPM) 提供了多少改进.
- **这是我们 headline ΔLER 的定义空间.**

### 6.3 PT-aware vs Markov ΔLER 作为 headline 指标 —— 如何测量

**headline 公式:**

```
ΔLER = LER_Markov(L̃_Markov(⃗s)) − LER_PT(L̃_PT(⃗s))
```

其中:
- `LER_Markov` = 使用 MWPM/DEM 解码器对相同含噪过程做出的错误率 (可视为 `p_fail` 但基于症候匹配/最小权重而非全似然).
- `LER_PT` = 使用本文过程的 PT-aware ML 解码器在相同噪声下的 LER (Eq. 45/49).
- **关键:** 两者对**同一过程张量 Υ** 操作, 区别在于解码器是否知道 Υ 中的时间相关结构.

**实验设计 (a la paper):**
1. 对给定的噪声模型 (参数: `p_err`, `J_NM`, `J_CT`), 构建合成过程张量 Υ (Eq. 17, 操作如前).
2. 计算 PT-aware ML 解码器: 遍历 L ∈ L_C, 对每个症候 ⃗s 计算 χ_HS 或 χ_CD, 取 argmax/argmin (Eq. 44/48). 得到 `p_fail_PT`.
3. 计算 Markov 解码器 LER: 方法 A (近似) —— 从 Υ 的边缘分布中提取 Pauli 错误率, 喂入 MWPM; 方法 B (精确) —— 将 Υ 与一个"忘记浴记忆"的修改过程张量 `Υ_Markov` 配对 (例如, 每步重置浴为初始态, 破坏时间关联). 得到 `p_fail_Markov`.
4. ΔLER = p_fail_Markov − p_fail_PT.

**预期行为 (理论预测):**
- `J_NM << p_err`: 浴效应可忽略, ΔLER ≈ 0.
- `J_NM ≈ 10 × p_err`: ΔLER 开始打开 (基于 Fig. 9c 的阈值).
- `J_NM >> p_err`: ΔLER 可能饱和, 因为两者都高.

## 7. 可操作的实现路径: 3 量子比特系统的完整 TN 构建

以下描述基于论文方法, 针对一个简化的 3 量子比特系统 (例如 Steane 码的子部分或一个 [[3,1,1]] 玩具码), 构建 PT-aware ML 解码器所需的完整张量网络, 每一步标注论文中的等价对象.

### 7.1 系统定义

- 数据量子比特: n = 3
- 逻辑量子比特: k = 1 (因此 n−k = 2 个 stabilizer generators)
- 浴量子比特: n 个私有浴 (B_1, B_2, B_3), 各 1 qubit
- 总量子比特数 (模拟时): n 数据 + n 浴 + 1 辅助 (Choi) = 7 qubits
- 症候测量轮数: 1 轮 (因此时间步数 = T_{n−k+1} = T_3, 3 个时间步)

### 7.2 张量组件清单

| 组件 | 形状/腿 | 对应论文 |
|---|---|---|
| **编码器 Π_enc** | 张量映射 H_logical(2) → H_data(2^3=8). 形状: (2, 8) 但 Choi 态为 (2×8) 的平方矩阵. | Eq. 38 |
| **每步错误块 U_k** (Fig. 7) | 对每个数据 qubit i: E_dep (Eq. 50) → U_NM (Eq. 51, 纠缠 B_i) → U_CT (Eq. 52). 综合为 MPO 形状: (dim_in, dim_out). | §4.1 |
| **过程张量 Υ_T3** | 3 时间步. 每步数据系统维度 2^3, 浴系统维度 2^3. 跨步骤浴保留. 总尺寸: 2^3 (输入 o_0) × (2^3 × 2^3)^(交叉) × 2^3 (输出 i_3). 即约 (8)^(7) ≈ 2^21 ≈ 2M 元素. | Fig. 8a, Eq. 17 |
| **症候仪器 Π_{x_j}** (j=1,2) | 对 stabilizer G_1, G_2 的投影: `π_{x_j} = (1 + (−1)^{x_j} G_j)/2`. Choi 态形状: (2^3, 2^3). | Eq. 25-26 |
| **纯错误 P(⃗s)** | 纯错误算子 (destabilisers), 例如 P_1, P_2. Choi 态形状: (2^3, 2^3). | Eq. 31 |
| **逻辑操作 L** | X_L 或 Z_L 等. Choi 态形状: (2^3, 2^3). | Eq. 36 |
| **恢复操作 R(L,⃗s)** | `R = L ⋆ P(⃗s)` via link product. Choi 态形状: (2^3, 2^3). | Eq. 36 |
| **大 tester C_{L,⃗s}** | `Σ Π_{x_1,x_2} ⊗ L ⋆ P(⃗s) δ_{x,output}`. 经典腿携带 2 比特症候. | Eq. 37 |
| **身份过程张量 I** | 完美第二轮所需的恒等过程张量. 形状同 Υ. | Eq. 42 |
| **逻辑恒等通道 Υ_1** | 逻辑 qubit (2 维) 上的恒等通道的 Choi 态. | Eq. 43 |

### 7.3 收缩顺序 (按论文 Fig. 8b 的顺时针流动)

```
Step 1: Υ̃_bath = 构建过程张量 Υ_T3
         对于 t=0→2:
           初始化浴态 |0⟩_{B_i}
           应用 U_t = E_dep ∘ U_NM ∘ U_CT (每步对所有数据 qubit 和浴 qubit)
           记录输入/输出腿 (o_t, i_{t+1})
           (在 t=2 后结束, 浴跨步保留)
          → 得到 Υ_T3 (2^3 入, 2^3 出)

Step 2: Υ_enc = Π_enc ⋆ Υ_T3 (链接编码器到过程张量)

Step 3: 对每个症候 ⃗s ∈ {00, 01, 10, 11}:
          ← 这可以通过一次性 TN 收缩获得所有 ⃗s 的矩阵,
             因为经典比特 (症候结果) 留在开放腿上.

Step 4: 构建 Q(L, ⃗s) = Π_dec ⋆ I_T3:2T3+1 ⋆ C_{Lpdc, spdc} ⋆ R(L, ⃗s)
          (噪声无关, 对给定码单次构建)

Step 5: χ_HS(L, ⃗s) = ⟨⟨Q(L, ⃗s) ⋆ Υ_enc | Υ_1⟩⟩ (Eq. 43)
         对所有 L 和 ⃗s 同时收缩 → 得到 2^(n−k) × |L_C| 矩阵

Step 6: L̄(⃗s) = argmax_L χ_HS(L, ⃗s) (Eq. 44)

Step 7: p_fail = 1 − Σ_{⃗s} χ_HS(L̄(⃗s), ⃗s) (Eq. 45)
```

### 7.4 对我们 3-qubit 玩具的实现建议

**成本估算:**
- 精确 TN (状态向量): `4^{2×3+1} × 2^2 = 4^7 × 4 = 16384 × 4 = 65536` 维向量. **在消费级 GPU 上完全可行** (作为我们概念验证的有力工具).
- MPS: 不需要, 因为精确收缩已可行. 但可以用作 MPS 调试基准.

**quimb 实现:**
- 使用 `quimb.tensor.Tensor` 和 `TensorNetwork` 构建 Fig. 8b 的结构.
- 使用 `cotengra.HyperOptimizer` 优化收缩顺序.
- 测试点: 将 `J_NM = J_CT = 0` 时的 `p_fail` 与已知的 iid 去极化结果对比.

**扩展路径:**
- 3-qubit 验证通过后 → Steane [[7,1,3]] 确认论文结果复现.
- 增加共享浴版本 (修改 Eq. 51: 一个浴作用于多个数据 qubit).
- 增加多轮 (将时间步从 3 扩展到 3×rounds), TN 随之增长.

## 8. 最终评判 (Verification)

### 8.1 对论文三个核心问题的答案

1. **PT-aware 解码器比 Pauli/Markov 解码器好多少, 在什么尺度下?**
   - **论文未测量头对头比较.** 它的数字是内在最优 LER, 不是 ΔLER. 我们需自己添加.
   - 有证据: 相关性惩罚在 `J ≳ 10·p_err` 时开启 (Fig. 9c). 但这是最优解码器下的内在惩罚, 不是不匹配解码器缺陷.

2. **什么样的非马尔可夫噪声?**
   - 逐 qubit 私有浴的 Heisenberg (XX+YY+ZZ) 耦合 → 时间关联. 相干 ZZ 串扰 → 空间关联.
   - **不是共享浴/共享潜变量.** 不产生真正交叉 qubit 的非马尔可夫关联. 这是与我们需求的根本差异.

3. **作为我们的解码器/可观测量的可复用性?**
   - **解码器构建: 高.** χ_HS/χ_CD 目标 + 链接积 Choi TN + p_fail 单次收缩是 directly portable.
   - **MPS 工程: 高.** quimb/cotengra, 索引排序, BEE 诊断, p_est/p_perf 分离.
   - **解码相关性验证: 中.** 确认了相关性噪声影响最优 LER, 但未关闭不匹配解码器无关的假设.
