## Executive summary [paper]

Introduces the **Machines for Autonomous Distinction (MAD)** framework: a process
discrimination paradigm where the discriminator is an autonomous quantum machine that
interacts with the process repeatedly, collects the full classical record of outcomes,
and stores quantum information in an internal memory of dimension d_A. Crucially, the
same instrument is applied at every time step — there is no time-dependent or
history-dependent adaptation — making the MAD a "memoryful but static" discriminator.

The central quantity is d^{(N)}_{MAD}(P^N, Q^N; d_A), the maximum distinguishability gap
achievable by a MAD with internal memory dimension d_A between two N-step processes P^N
and Q^N. This quantity is monotone non-decreasing in d_A, and increasing d_A systematically
closes the gap to the full strategy-norm distance (the ultimate distinguishability bound
allowing arbitrary adaptive strategies). The numerical demonstrations (Fig. 3-4) show that
even modest d_A = 2-4 captures a substantial fraction of the total distinguishability for
processes with temporal correlations.

**KEY FOR CLAIM 3:** The paper develops a **single-step description for recurrent
processes** (Section IV.B), which applies to processes where "the same system-environment
interaction is repeated at each step" — exactly our JC model with repeated rounds of
qubit-bath interaction followed by measurement. This description separates the generation
of new distinguishing information from the propagation/decay of prior information stored
in the bath (or the MAD's memory). The decomposition maps directly onto our coherence
(quantum memory) vs. finite-γ (classical record propagation) separation.

## Key equations/findings [paper]

### MAD distinguishability measure — Section III, Eq. (1)-(3)
```
d^{(N)}_{MAD}(P^N, Q^N; d_A) = sup_{MAD with dim H_A = d_A} |P(MAD outputs "P")
  − P(MAD outputs "Q")|
```
The supremum over all MADs with internal memory dimension exactly d_A. The measure captures
how well a memory-bounded autonomous quantum machine can discriminate between two N-step
quantum processes. d_A = 1 corresponds to the classical-memory-only case (no coherence
storage), and increasing d_A adds coherent (quantum) memory.

### Recurrent-process single-step decomposition — Section IV.B, Eq. (19)-(22)
For a recurrent process where the SE interaction is identical at each step:
```
ρ_A^{(k+1)} = Tr_E[ U (ρ_A^{(k)} ⊗ ρ_E^{(k)}) U† ]
```
The MAD's internal state update separates into:
- **Fresh distinguishing information** generated by the current-step interaction
- **Propagated information** from prior steps, stored in the internal memory
- **Decay/loss** of prior information through the interaction

This decomposition is derived for the specific case of repeated identical interactions —
exactly the JC model's structure (repeated qubit-bath swap-type interactions at each
discretized time step).

### Monotonicity in memory dimension — Theorem 1
```
d_A ≤ d'_A ⇒ d^{(N)}_{MAD}(·,·; d_A) ≤ d^{(N)}_{MAD}(·,·; d'_A)
```
Larger coherent memory never hurts distinguishability. The gap d^{(N)}_{MAD}(·,·; d'_A) −
d^{(N)}_{MAD}(·,·; d_A) is the **coherent memory advantage** — the additional distinguishing
power that comes from storing quantum (coherent) rather than only classical (outcome-record)
information.

### Single-step hierarchy — Proposition 3
For recurrent processes, the single-step MAD description implies:
```
d^{(N)}_{MAD}(P^N, Q^N; d_A) ≤ d^{(1)}_{MAD}(P^1, Q^1; d_A · N)
```
Any N-step strategy can be compiled into a single-step MAD with internal memory scaled by
N. This bound is generally not tight but establishes the scaling: adding more steps
compresses into larger required internal memory.

### Numerical demonstration — Fig. 3-5
- For processes with short temporal correlations (fast bath decay), d_A = 2 saturates
  the distinguishability gap — classical records suffice
- For processes with long temporal correlations (slow bath decay, large γ^{-1}), larger
  d_A is needed — coherent memory captures correlations that classical records cannot
- **Transition occurs at γ ∼ interaction frequency:** when the bath correlation time
  ∼ step duration, coherent memory helps; when γ is large (Markovian limit), it doesn't

## Relevance to project [ours]

**The MAD framework provides the OPERATIONAL LANGUAGE to frame what our TV distance
actually measures — the coherent memory advantage between the exact JC model and the
incoherent null model.**

1. **MAD internal memory d_A → "coherent memory dimension" of the bath:** In the JC
   model, the bath acts as the MAD's internal memory — it stores quantum information
   about past qubit states through the correlation function C(τ) = e^{−γτ}. The
   effective d_A is approximately the number of bath correlation times that fit into
   the total protocol duration: d_A ∼ floor(T · γ) for T the protocol length. When
   γ ≫ 1/T (Markovian, d_A = 1), the bath provides no coherent memory; when γ ∼ 1/T,
   d_A > 1 and the bath stores coherent information that the null model misses.

2. **Coherent memory advantage → TV residual:** The TV distance between exact and
   null-model statistics is exactly the coherent memory advantage of the exact process
   over the null model. The null model corresponds to d_A = 1 (only classical outcome
   records). The exact JC model has d_A > 1 (coherent memory in the bath). Our
   decomposition of the TV residual into "coherent" vs. "incoherent" parts is the
   operational decomposition of the MAD distinguishability gap.

3. **Single-step description → repeated JC interaction rounds:** Our discretized JC
   model (repeated interaction + measurement rounds) is exactly a recurrent process
   in the MAD sense. The single-step decomposition (Eq. 19-22) says that each round
   adds fresh distinguishing information (the new qubit-bath interaction) and
   propagates/decays prior information (the bath correlation C(τ)). The Claim 3
   decomposition into "coherent" (off-diagonal qubit-bath entanglement) and
   "finite-γ" (exponential decay of prior information) maps directly onto this
   separation.

4. **γ ∼ interaction frequency transition → the Claim 3 cross-over prediction:**
   The numerical results (Fig. 3-5) show a transition at γ ∼ interaction frequency.
   When γ ≪ interaction frequency (strongly coupled, finite-γ), coherent memory
   dominates and the TV residual is large. When γ ≫ interaction frequency
   (Markovian limit, effectively infinite γ), the TV residual vanishes. The Claim 3
   decomposition must predict this cross-over and quantitatively separate the
   coherent-memory contribution from the classical-record contribution.

5. **Decomposition protocol:** The MAD framework suggests a concrete protocol for
   decomposing the TV residual: (a) compute d^{(N)}_{MAD}(exact, null; d_A=1) which is
   zero by construction (null model has no coherent memory); (b) compute
   d^{(N)}_{MAD}(exact, null; d_A>1) for increasing d_A; (c) the increase with d_A
   quantifies the coherent memory contribution to the TV residual; (d) the asymptotic
   d_A → ∞ value is the total TV distance; (e) the finite-γ contribution is the
   portion that requires d_A > 1 to capture — i.e., the coherent memory advantage.

## Limitations
- MAD framework assumes the same instrument at each step — our JC model uses the same
  interaction but the measurement instrument may vary (basis rotation for X, Y, Z
  parities), requiring extension
- The single-step compilation bound (Proposition 3) is loose — the actual d_A requirement
  may be much smaller than the N-scaling suggests
- No explicit extension to non-projective measurements (our soft-readout regime requires
  POVM instruments)
- Numerical demonstrations use small d_A (2-4); the scaling to large N (long circuits
  with many rounds) is not demonstrated
