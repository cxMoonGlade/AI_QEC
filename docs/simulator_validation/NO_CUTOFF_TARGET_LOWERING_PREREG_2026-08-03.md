## 2. Exact pair-transition program

### 2.1 Term semantics and Pauli convention

At a checkpoint, one symbolic term denotes

\[
\alpha P_L\,|\psi_j\rangle\langle\psi_j|\,P_R,
\]

together with the persistent latent coordinate, live classical frame, and
emitted Record prefix.  The Pauli convention is

\[
P(x,z)=i^{x\cdot z}\prod_q X_q^{x_q}Z_q^{z_q}.
\]

Phases generated by Pauli multiplication and Clifford conjugation multiply
`alpha`; they are never dropped.  The reference state begins at all-zero on
the declared qubits.  This is exact because the leading `R` resets every
declared qubit before use.  The reference stabilizer evolves only through `H`
and `CX`.  Reset and measurement are represented by complete Pauli-expanded
instruments, so no outcome-dependent reference tableau is hidden outside the
key.

Checkpoint zero has exactly two declared initial terms, not an executed sparse
map:

```text
m=-1: alpha=1/2, P_L=I, P_R=I, observable_0_accumulator=0,
      live_raw=(), Record=()
m=+1: alpha=1/2, P_L=I, P_R=I, observable_0_accumulator=0,
      live_raw=(), Record=()
```

Their coefficients are the persistent-sign prior.  Every other checkpoint-zero
codec assignment totalizes to exact zero in a later ADD.  The public pair
program declares both terms and never chooses one of them.

For a Clifford `V`, conjugate both `P_L` and `P_R` and every signed reference
stabilizer by `V`.  For the coherent primitive, for `l,r in {0,1}` emit

```text
left operator:  Z^l P_L
right operator: P_R Z^r
multiplier:     (-i*m*s)^l * (i*m*s)^r * c^(2-l-r)
```

with `m` preserved symbolically.

For any instrument Kraus component `K_b=sum_a k_(b,a) P_a`, emit every pair
of left and adjoint-right Pauli components with multiplier
`k_(b,a) * conjugate(k_(b,a'))`, left operator `P_a P_L`, and right operator
`P_R P_a'`.  The complete local definitions are

```text
M outcome b:  K_b = Pi_b = (I + (-1)^b Z)/2; emit raw b; q remains measured.
MR outcome b: K_0 = (I+Z)/2, K_1 = (X+iY)/2; emit raw b; q resets to |0>.
R channel:    sum over the same K_0,K_1 Kraus branches; emit no raw bit.
```

Thus `M`, `MR`, and `R` each own the full eight Pauli-component-pair rows
before exact canonical merging (two outcomes/branches times four component
pairs).  `R` sums the branch label rather than retaining it.  `M` and `MR`
retain exactly their emitted raw bit if it is live.

### 2.2 Signed stabilizer cosets and frame layout

Every checkpoint binds the rank-`n` signed stabilizer tableau for
`|psi_j>`, its independently checkable GF(2) RREF basis, and its basis ID.
Columns are exactly

```text
x[q in declared order], then z[q in declared order]
```

with leftmost pivots.  Row multiplication is exact Pauli multiplication and
retains the phase exponent modulo four.  Ket/left canonicalization multiplies
pivot stabilizers on the **right** of `P_L`; bra/right canonicalization
multiplies them on the **left** of `P_R`; the resulting phase multiplies the
coefficient.  Canonical representatives have zero in every pivot column.
Rank loss, anticommuting stabilizers, a non-`+1` signed generator for the
reference state, or a non-idempotent reduction is a schema failure.

The reachability-independent key codec order is exactly

```text
L.x, L.z, R.x, R.z in declared-qubit order;
latent m (0=-1, 1=+1);
observable_0_accumulator;
live raw-measurement slots in increasing absolute raw ordinal;
emitted Record prefix in chronological order.
```

The observable accumulator exists from checkpoint zero, starts at zero, and
persists until finalization.  A raw slot is live from its `M|MR` event through
its last detector/observable consumer, inclusive, and is absent afterwards.
Dropping a dead raw coordinate means exact summation/merging, never
postselection.  `DETECTOR_APPEND` XORs its resolved operands and appends the
bit to the Record prefix.  `OBSERVABLE_XOR` updates the accumulator in listed
operand order.  `FINALIZE_RECORD` appends that accumulator and removes it from
the live frame.  Invalid full Pauli codes, noncanonical pivot bits, invalid
latent codes, padding, and invalid frame/Record coordinates totalize to exact
zero in a later ADD; they are not reachable-state ordinals.

`ExactPairTransitionProgram.v1` contains the neutral-program SHA, exact field
identity, signed basis catalog, checkpoint basis/layout/codec manifests, and
one complete symbolic transition kernel reference per neutral event.  It
contains no current coefficient map, sparse key, frontier, support count, peak,
probability, or execution result.

## 3. Dynamic ADD relation program

The ADD lowering owns no second physical semantics.  For each event it binds
the exact `ExactPairTransitionProgram` event hash and provides only:

```text
input codec and validity predicate;
output codec and validity predicate;
input bits followed by output bits as the combined relation order;
the pair-kernel substitutions/clauses needed to compile an exact relation;
all input-bit abstraction and output-to-next-checkpoint rename maps;
the canonical exact ADD policy already qualified by the micro-owner.
```

The relation compiler is a pure function of the pair event and its two codecs.
It must not accept or inspect a current root, sparse map, reachable key set, or
frontier.  This static stage does **not** compile a target relation root and
does not call `advance`.  A relation instance is exercised only on registered
tiny synthetic codecs where complete truth-table comparison is finite.

`DynamicADDRelationProgram.v1` contains a pair-program hash, event-for-event
semantic hashes, relation/abstraction/rename specs, and the exact canonical
policy.  It contains no ADD root or node table, no pair state, no node count,
and no route metric.  Any duplicated or changed physics coefficient relative
to the pair program is a schema failure.

The target-specific independent ADD check is not limited to tiny truth tables.
For every event of all eight source cells, an independent source-text/RREF
oracle reconstructs the input/output codec fields, validity constraints,
component-row normal form, abstraction set, and rename map without importing
neutral, pair, or ADD owner helpers.  The normal form is a canonical sorted sum
of rows

```text
(input-field predicates, output-field assignments, exact A multiplier)
```

with the symbolic latent bit retained.  It must equal the pair event's normal
form, and the ADD event may contain only the hash of that equal normal form plus
the registered maps.  Complete truth tables additionally check every row for
the finite witness codecs in Sec. 6.  This establishes static target relation
semantics; it still does not compile a target relation root.

## 4. Retained-boundary factor network

The TN path consumes the neutral program directly and independently of pair
and ADD code.  Density indices have domain four with row-major encoding
`2*ket+bra`; sign, raw, parity, consumer, and Record indices have domain two.
Every factor instance has an ordered scope, exact shape, row-major exact table
template ID, and stable provenance.  The template catalog stores every table
entry explicitly in `A`, including structural zeros; missing/sparse/pruned
tables are forbidden.

The exact templates and factorization are:

- `INIT0(q)=1[q=(0,0)]` and final `TRACE(q)=1[ket=bra]` for every declared
  qubit;
- `H` and control-first `CX` density superoperators
  `S[(a,b),(c,d)]=U[a,c]*conjugate(U[b,d])`, with two-qubit basis order
  `|00>,|01>,|10>,|11>`;
- `COHERENT_Z(q_in,q_out,mu)` from
  `U_mu=diag(c-i*mu*s,c+i*mu*s)` under the same superoperator rule;
- `R(q_in,q_out)=1[q_in.ket=q_in.bra]*1[q_out=(0,0)]`;
- `M(q_in,b,q_out)=1[q_in=(b,b)]*1[q_out=(b,b)]`;
- `MR(q_in,b,q_out)=1[q_in=(b,b)]*1[q_out=(0,0)]`;
- unary `HALF` prior on sign-chain `z_0`, ternary equality
  `SIGN_EQ(z_(j-1),mu_j,z_j)`, and terminal unary `ONE(z_L)`;
- a chronological raw-measurement COPY chain whose consumers sort by
  `(Record declaration ordinal, operand ordinal)`, with a distinct consumer
  index for every use and an all-ones terminal; the one-consumer case still
  owns one ternary COPY and no-consumer raw bits go directly to `ONE`;
- explicit unary zero accumulator, fixed left-associated ternary XOR chain in
  resolved operand order, one output index per detector and observable zero,
  and one unary labelled `KEEP` factor on every Record output.

Every sign index uses the exact codec `0 -> -1`, `1 -> +1`.  In that row order,
`HALF=[1/2,1/2]`, `ONE=[1,1]`, and `SIGN_EQ[a,b,c]` is one exactly when all
three bits are equal and zero otherwise.  `COHERENT_Z[...,mu=0]` therefore uses
`m=-1`, while `mu=1` uses `m=+1`.  This codec and all three literal tables are
part of the template identity, not prose-only conventions.

`QUBIT_COORDS` and `TICK` remain hash-bound markers and create no factors.  The
network keeps every detector/observable index non-eliminable, but this stage
does not construct or optimize any elimination order.  It does not contract a
fixed-Record scalar or materialize the joint output tensor.

`RetainedBoundaryFactorNetwork.v1` contains the neutral-program SHA, ordered
index/domain catalog, exact table catalog, ordered factor instances, complete
Record boundary, marker ledger, raw consumer ledger, and sign occurrence
ledger.  It contains no heuristic or exact treewidth, bucket burden,
contraction order, probability, or route disposition.

   retained-output tensors with direct density-matrix branching.

## 8. Negative controls and non-degeneracy

- A synthetic source with one unsupported `X`, `MPP`, feedback target, or
  observable index one must fail closed; silent dropping is forbidden.
- A synthetic invalid `rec[-k]` before `k` measurements must fail at neutral
  validation.
- Two public neutral programs that differ only by a selected sign are
  forbidden because no selected-sign field exists; attempting to add it must
  fail strict reload.
- On registered one-qubit witnesses, replacing persistent sign by independent
  per-site signs must change at least one exact retained-output entry; otherwise
  the non-Markovian control is degenerate and qualification fails.
- Reversing a raw consumer list, omitting a component pair, swapping ket/bra
  density digits, or changing a coherent coefficient must change the
  independently reconstructed object and trip its designated test.
- Swapping the sign codec or controlled-channel sign-row interpretation must
  trip `tn_sign_codec_swapped` at static table comparison; equality of the
  symmetric half-weighted contracted mixture is explicitly insufficient.
- Reordering JSON object keys alone must not change semantic content after
  canonical serialization; reordering semantic event/factor lists must change
  their bound identities.
