## Project application

### Current CZ leakage owner

`src/error_coupling_simulator/mechanisms/cz_leakage.py` currently states that the paper's `g` is the
bare `J1`, and describes a simulation fit as resolving the paper's convention. The source does not
make that redefinition. A project derivation may choose `J1` and validate its own Hamiltonian, but it
must not present that choice as a Miao source fact or use Miao as an independent coefficient oracle.

The same module's `transport_fractions` computes state-to-state probabilities from a closed-system
propagator. Miao's reported `Delta P_t` is instead a with-CZ minus no-CZ population difference that
includes the paper's preparation/readout protocol. The current model diagnostic can remain, but its
documentation and any comparison must name the observable mismatch.

`CZParams.t_gate=25 ns`, `T1=75 us`, and `Tphi=75 us` may remain project-design values. Miao's table
supports only a hypothetical d5/d7 simulation model, and it lists `T2`, not a separately identified
pure-dephasing `Tphi`. The current “Sycamore default” and unversioned Table S1 attribution are not
supported.

### Current qutrit preset

`src/error_coupling_simulator/frontend/experiments.py` already records that the Fig. 3c value has no
identity transform to its project-channel target and classifies the preset as project design. That
boundary is supported. The exact source object is “average leakage population produced during a
cycle in the reported surface-code protocol,” not a Wood--Gambetta channel leakage rate.

### Current source-to-level-map certification

The paper directly names `|30> <-> |12>` and `|31> <-> |22>` as transport processes, so those level
pairs are source-supported. It does not establish the numerical coefficient used by an arbitrary
two-site Hamiltonian term, nor does it make a hand-typed level table an independent oracle for a
carrier that shares the same paper interpretation. Varbanov must be read before that audit can
close.

### Current conditional phase comment

The approximately `0.65 pi` phase is measured over 20 pairs under the paper's modified Ramsey
protocol. It supports the existence and device-scale magnitude of a leaked-neighbour phase in that
experiment, not a universal signed Hamiltonian coefficient.

No source file is changed in this literature-closure step.

## Competing evidence and kill conditions

- Varbanov et al., arXiv `2002.07119`, is the preselected direct multi-level Hamiltonian source. It
  must be reread before choosing a coefficient convention or calling the current transport path
  literature-closed.
- A from-scratch Duffing ladder gives `g_11,20=sqrt(2)J`, `g_21,12=2J`, and
  `g_30,21=sqrt(3)J`. This is a project derivation used only to expose the source-normalization
  conflict; it is not inserted into the source-only note.
- A publisher correction that changes SI S1, a device-specific pulse calibration that identifies
  the actual interaction coefficient, or a protocol reconstruction showing equality between
  baseline-subtracted `Delta P_t` and the current model probability would reopen the affected rows.
- Failure to preserve the versioned Table locator or the measured-versus-hypothetical distinction
  kills any numerical provenance claim built from these values.
