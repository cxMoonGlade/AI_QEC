# Coverage-validation contract for the repeated-QEC memory overview

## Frozen decision packet

| Field | Frozen value |
|---|---|
| Decision/consequence | Determine whether targeted source review, adversarial search and bidirectional citation tracing change the Section 5 decoder/robustness/transfer judgments, the six Section 3 approach rows, or the representation–interface–computation comparison frame |
| Mechanism | Temporal dependence made usable through a continuing physical or latent carrier, an ordered multicycle record, or a model-conditioned intervention; no assumption that drift, leakage, recurrence or generic noise awareness is automatically temporal memory |
| Observable/record object | Ordered syndrome or detector record; decoder-visible side information; inferred latent state; multicycle/logical performance; uncertainty; calibration and computational cost; held-out transfer result |
| Mechanism-to-observable bridge | A source-explicit chain from the memory-bearing representation or record history to changed decoder/control information and then to a common repeated-QEC task metric |
| Predicted direction/scale | Missing and source-dependent; no benefit, robustness or transfer is assumed before search |
| Alternative formulations/invariants | Generic noise calibration, nonstationary drift, spatial or Pauli-type correlation, soft readout, architecture capacity and additional compute can improve decoding without isolating temporal-memory access |
| Possible no-go or contrary result | No matched information ablation; event or regime selection; no population average or uncertainty; same data for fitting and evaluation; per-setting retraining or retuning; wrong-model failure; benefit lost under held-out shift; formal approach without repeated-QEC output |
| Implementation target | Reader-facing coverage judgment for a graduate technical overview; no simulator implementation, work package or research proposal |

## Admission and stopping rules

- Abstracts, snippets, citation counts and local RAG hits are discovery only.
- A source changes a row only after fixed-full-text review with exact locators and a source-local
  comparison boundary.
- A negative field-level judgment requires adversarial terminology variants and citation-chain
  coverage; otherwise the row remains `missing`, not `confirmed-literature-gap`.
- A citation neighbor is added to the main comparison only if it supplies a complete approach bundle
  and changes representativeness, not merely because it cites or is highly cited.
- `F1` fails the current frame only if a scientifically important source object is systematically
  misdescribed or loses a necessary dimension, not merely because one cell is absent.
