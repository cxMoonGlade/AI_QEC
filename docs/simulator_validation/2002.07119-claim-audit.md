Direct algebra exposes three printed Appendix-D defects:

- Eq. (D11) prints a zero **anticommutator** for four-overlap X/Z checks; the correct relation is a

  three-site anticommutator.

  changes neither normalized post-measurement states nor probabilities.

These are recorded defects, not silent repairs to the source.

## Project application

The source does not determine a unique physical representative for this repository's data echo.
“Identity on leakage” fixes the leaked entry once a computational-block matrix is chosen, but a
global phase of that computational matrix becomes a relative computational/leakage phase in a
direct-sum embedding. Thus `Y direct-sum 1` and `(-iY) direct-sum 1` are not interchangeable in the
presence of cross-sector coherence merely because `Y` and `-iY` differ by a qubit-global phase.
Varbanov's Appendix-B null is a useful counterexample: its measurement-interrupted schedule and
production incoherent-leakage approximation do not expose that sensitivity. It does not establish a
general invariance.

The one-half individual marginal supports only a local symmetry:
`Bernoulli(1/2) XOR c` has the same one-bit distribution. It does **not** make the complete Record
unobservable. Same-round products, supercheck parity, raw-outcome bias, and temporal correlations can
still change. Fig. 10 is particularly important here: its phase scan is the supercheck statistic,
not the individual neighboring-check statistic.

Appendix G shows that an intended gate layer can be paired with deterministic detector bookkeeping,
but it does not solve this project's reconstruction problem. The proposal concerns ancillas, assumes
the pulse is trivial on leaked ancillas, and is evaluated using hidden density-matrix leakage
intervals. It therefore cannot be imported as an exact mapping from public detector bits to a
data-trajectory-conditioned logical frame.

The prior-mechanism novelty question is closed against the project. Bultink et al.
arXiv:1905.12731v1 explicitly attribute the repeated-ZZ `++--` leakage pattern to the physical data
echo flipping the effective stabilizer each round. The remaining issue is simulator semantics:
after dividing out only the deterministic leakage-free reference sign, what should the Record retain?
Neither Varbanov nor Bultink defines an exact trajectory-conditioned logical correction.

The documentation-safe conclusion is:

> Preserve the residual detector/logical-observable outcome as physical Record content under the
> declared qutrit model. Do not erase it as a global frame bit, infer it from evaluator-only leakage
> truth, or call an HMM posterior an exact correction.

The local script `scripts/within_cycle_echo_trajectory_frame_probe.py` remains a project-side algebra
probe, not literature evidence. Its conclusions must remain in the project-inference layer.
