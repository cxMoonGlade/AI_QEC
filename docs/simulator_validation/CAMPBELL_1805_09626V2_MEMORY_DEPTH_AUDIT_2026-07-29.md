## Project application

The source and the proposed benchmark must remain distinct:

- A Quimb carrier can represent a joint pure state only after the project separately freezes pure
  initial factors and globally unitary evolution, or supplies an explicit purification or trajectory
  construction. Equation (1) itself permits mixed density operators.
- Reproducing the paper's fixed-memory equivalence would require fixed memory sites, fresh
  ancillas, the source's memory–fresh-ancilla collisions, swap/index movement, partial traces, and
  the whole-memory-before-intra-environment schedule. A persistent register alone is not that
  equivalence.
- The proposed \(2\times w\) closed system–memory ladder instead reuses a finite set of system and
  memory sites under joint unitary evolution. It is a project-defined finite-memory unitary
  benchmark. It neither reproduces Campbell et al.'s advancing collision stream nor implements the
  Eqs. (14)–(18) fixed-memory replay, and it must not cite their equality as its own.
- The three coupling choices “one axis,” “two axes,” and “isotropic” are a project-defined taxonomy
  inspired by Eq. (2). The source defines the Hamiltonian and identifies the isotropic
  partial-SWAP case; it does not rank these choices as noise-model complexity.
- A Bernoulli event mask, a PEPS layout, a bond cap, and any GCAPEPS/ordinary-PEPS comparison are
  independent project choices and receive no correctness or efficiency guarantee from this source.

The source-supported bridge that remains usable is narrower: finite interaction range can make a
finite enlarged-state description sufficient for this collision-model class, and the reduced
system process can be tested with the trace-distance diagnostic. Whether the project's closed
ladder exhibits such a revival is an experimental question, not a consequence of Campbell et al.

## Competing evidence and kill conditions

- The dense witness must use the same collision map, collision schedule, and environment
  preparation for both initial system states.
- No trace-distance revival means only that the registered pair failed to witness memory.
- System–memory entropy may grow, fall, or revive. It is neither the source's definition of
  non-Markovianity nor guaranteed to increase with the number of rounds.
- If the implementation claims Campbell fixed-memory equivalence but omits fresh ancillas,
  swaps/index movement, partial traces, or the p. 7 timing condition, that equivalence claim fails.
- If the implementation uses the interleaving excluded by the p. 7 qualification, the source still
  supports the last-\(d\)-ancilla relevance statement but not the same-fixed-ancilla replay.
- The Markovian embedding supplies no PEPS contraction, truncation, runtime, or bond-dimension
  guarantee.
