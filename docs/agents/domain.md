# Domain docs

This is a single-context repository.

## Before exploring

- Read the root `CONTEXT.md` and use its glossary and claim boundaries.
- Read relevant decisions under `docs/adr/` when that directory exists.
- Read `docs/SIMULATOR.md` first for simulator work; it is the binding product and scientific
  contract.
- Follow the more specific owner routes in `AGENTS.md`, including module READMEs and the test
  codebook.

If an optional context or ADR path does not exist, proceed without treating its absence as a request
to create documentation.

## Vocabulary and conflicts

Use the terms defined in `CONTEXT.md` rather than inventing synonyms. Surface any conflict with a
current ADR or binding simulator contract explicitly; do not silently override it.
